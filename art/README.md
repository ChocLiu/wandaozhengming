# 美术源文件（art/）

存放美术**源文件**（Krita/PS 工程、ComfyUI 工作流、3D 源文件）。**成品才进 `godot/assets/`**——源与成品分离，成品可随时整体替换。

风格方向：2D 国风水墨手绘（质量线不输鬼谷八荒），P2 试点 3D 卡通渲染。详见 [docs/06_美术与音效/视觉风格指南.md](../docs/06_美术与音效/视觉风格指南.md)。

## 目录结构（内容类型优先，维度次之）

```
art/
├── 01_概念图/            # 风格探索、种族/场景概念——本目录全部视为 AI 探索，不进游戏
├── 02_角色立绘/          # 立绘源文件（主角/重要NPC/通用模板）+ ai_generated/
├── 03_场景资产/          # 2D 手绘战场/地图/地形件 + ai_generated/（3D 场景归 06）
├── 04_UI界面/            # UI 切图、图标、字体（国风字体收藏——永远 2D）
├── 05_特效/              # 功法特效帧动画/粒子素材 + ai_generated/
├── 06_3D资产/            # P2 试点起：角色模型/绑定动画/材质（3D 场景届时建 场景/ 子目录）
└── _ai工作流/            # ComfyUI 工作流 JSON + 提示词模板（集中留档，下划线开头=工具目录）
```

设计理由：UI 永远 2D、概念图/立绘天然 2D，只有「场景」和「角色」会碰 3D——按内容分顶层、维度在内部细分，同题材资产不散。

## 命名规范

- 模式：`对象_用途_v序号.ext`，如 `主角_半身像_v3.kra`、`散修_焚天诀_战斗帧_v1.png`
- 版本递增，废弃稿移入本目录 `废弃/`（不提交 git，只留本地）

## AI 内容归档规则（Steam 披露依据）

1. **原始 AI 输出**：放对应类别的 `ai_generated/` 子目录，随图留同名 `.txt` 记提示词与模型
2. **含 AI 成分的成品**（人工精修后仍用于游戏）：文件名带 **`_ai` 后缀** + 同目录同名 `.txt` 提示词留档——商店页披露时按此清单申报
3. **工作流模板**：复用性 ComfyUI 流程存 `_ai工作流/`（版本化 JSON）
4. 完全人工绘制/可商用素材库资产：无需标注
5. 红线：无法说明来源的 AI 素材不进游戏（《Steam发行策略》§4）

## 其他

- 音频源文件在 `../audio/`（与 art 平级）
- 大文件（>10MB）暂不入 git，存本地 `art/_本地备份/`（已在 .gitignore 用 `_` 前缀约定之外——建目录时再补规则）
