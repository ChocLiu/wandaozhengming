# 游戏定位与设计支柱

> 状态：初稿 v0.2 · 2026-08-30 · 待与制作人迭代
> 本文档是全部设计的「宪法」——后续所有系统设计、功能取舍都以这里的原则为准。任何新系统提案必须先回答：它服务哪根支柱？它违反哪条红线？

---

## 1. 名称（暂定）

- 中文名：**《万道争鸣》**（万道：多种族多道路；争鸣：百家争鸣之意——道统之争，也是玩家自创功法与天道之争）
- 英文名候选（Steam 用，【待定】）：*Myriad Paths Resound* / *Ten Thousand Ways* / *Daos Contending*
- 仓库代号：`wandaozhengming`（改名随时可行，文件夹重命名即可）

## 2. 一句话定位

**一款以「机制组合」为核心的开放沙盒修仙 RPG：每个种族、每门功法都带来一套真正不同的玩法规则；成长来自悟道与机缘，而非刷数值；玩家自创的功法可以开宗立派、被整个世界的 NPC 学习。**

- 平台：PC（Steam）先行
- 引擎：Godot 4.7 · 2D 像素/手绘
- 战斗：回合制策略（ATB 进度条变体，部位/要害/破防博弈）
- 框架：开放沙盒 · 自由修途

## 3. 目标玩家

- 修仙题材爱好者，但**厌倦了数值堆砌**的人——想要「我真的在修一条独一无二的道」的代入感
- 策略/构筑类玩家（喜欢杀戮尖塔、博德之门 3 式的机制组合）
- 沙盒玩家（喜欢矮人要塞/环世界式的系统涌现故事）

## 4. 三大设计支柱

### 支柱一：道即机制（Daos are Mechanics）

功法、种族、境界带来的必须是**玩法规则的变化**，而不是数值变化。

- 一门功法 = 一套新机制（新的资源循环、新的操作方式、新的信息），而不是「攻击力 +10%」
- 不同种族 = 不同的修炼模式（修炼方式、突破方式、寿元结构完全不同），而不是换个属性加成的皮肤
- 境界突破 = 解锁新的**规则权限**（如灵境解锁神识感知、真境解锁领域），而不是乘区膨胀

### 支柱二：万法皆可组（Everything Composes）

所有功法机制通过统一的「五大交互面」（状态 / 资源 / 场地 / 单位 / 时序）自由组合，**1+1 必须产生新的玩法**，而不是数值叠加。

- 组合空间是本游戏的核心乐趣与深度来源
- 玩家能做出**策划没想到的组合**，且它真的能用——这是最高成就
- 自创功法（嫁接 → 推演 → 立道）把组合深度推到极致

### 支柱三：世界是活的修途（A Living Cultivation World）

- 功法在 NPC 之间传承、被 NPC 改良、兴衰演化
- 玩家自创的功法进入「世界功法库」：可传道、开宗立派、被 NPC 学习，真正改变世界
- 死亡不是终点（死亡三途：兵解 / 执念 / 轮回）
- 玩家争的终极目标：把自己的道**写进天道**（呼应世界观主线「遁去的一」）

## 5. 反套路宣言（本游戏明确不做的事）

| # | 老套做法 | 本游戏的做法 |
|---|---|---|
| 1 | **抽卡**获得功法/角色 | 功法靠拜师、机缘、感悟、抢夺、自创获得，每次获得都有世界内的因果 |
| 2 | **经验条**打怪升级 | 无经验值。成长来自「悟」（经历事件、战斗、讲道产生感悟），感悟用于推演功法与突破 |
| 3 | **数值膨胀**境界压制 | 境界是规则权限的质变，高境界胜在「能做更多操作」，不是数值乘区 |
| 4 | **刷词条装备** | 法宝是「道的载体」：有器灵、有性格、有历史，与修士双向选择，本命法宝养成线，无随机词条 |
| 5 | **一键扫荡/挂机** | 无自动战斗，每场斗法都是有决策的博弈 |
| 6 | **永死→读档** | 死亡是内容：兵解转器修、执念转鬼修、轮回转世（可找回前世传承） |
| 7 | **数值战力排行榜** | 不设战力数字，强弱在机制对抗中体现 |
| 8 | **氪金成长** | 单机买断制，无内购 |

> 红线检查单（评审任何新系统时逐条过）：是否引入了新机制？是否可与其他机制组合？是否只是数值变化？是否破坏世界逻辑（如凭空掉落装备）？

## 5.1 用语风格红线（仙侠风）

游戏内一切文本（部位、状态、解说、文案）必须用**仙侠用语**，禁用现代医学术语：

| 禁用 | 使用 |
|---|---|
| 大脑 | 头部 / 天灵 |
| 心脏 | 心脉 |
| 大动脉 | 命脉 |
| 躯干 | 胸腹 |
| 四肢 | 手足 |
| 手 | 手腕 |

- 系统数值名（体力 / 玄力 / 移速）属游戏术语，不受此限；但进入解说与文案时优先用文言表达
- 评审任何新名词时先问一句：**「修士会这么说吗？」**

## 6. 竞品分析

| 游戏 | 学习点 | 回避点 |
|---|---|---|
| 鬼谷八荒 | 修仙题材的爽感循环、量大管饱的内容填充 | 本质是数值修仙+刷词条——我们要做的是它的**反面** |
| 觅长生 | 修炼细节模拟（功法/丹药/突破仪式感）到位 | 路线单薄，后期重复；功法仍是数值换皮 |
| 太吾绘卷 | 复杂系统的野心、世界模拟的深度 | **教训**：范围失控、内容填充多年难产——我们必须先深后宽、严格控制范围 |
| 了不起的修仙模拟器 | 门派生态、弟子传承网络——「传承」的玩法化 | 经营模拟的界面复杂度劝退部分玩家 |
| 矮人要塞 / 环世界 | 系统交互产生涌现故事——这正是「万法皆可组」要复现的乐趣 | 学习门槛过高 |
| 杀戮尖塔 / 博德之门3 | 构筑乐趣、机制组合的清晰呈现 | —— |

**结论**：市场已被「数值修仙」教育过一轮，玩家对同质化疲惫。「机制修仙」是蓝海，但风险是**实现难度**——所以试水期只验证核心假设（见路线图）。

## 7. 核心乐趣假设（试水期要验证的命题）

1. **H1 机制差异假设**：剑修玩家和阵修玩家会感觉自己在玩两个不同的游戏，且都好玩。
2. **H2 组合涌现假设**：主辅功法组合能产生策划未预设的有效玩法（涌现 > 设计）。
3. **H3 悟道成长假设**：没有经验条的「悟道」成长循环（机缘→感悟→突破）依然有持续的动力感。
4. **H4 博弈假设**：回合制斗法像下棋（信息、预判、规则对抗），而非数值比较。

P0 原型只为验证 H1/H2/H4；H3 在 P1 垂直切片验证。**任何一个假设被证伪，都要先改设计再前进**——这就是「试水」的意义。

## 8. 试水期成功标准

- 用两个机制完全不同的功法通关同一个战斗关卡，体验截然不同
- 自己（或玩家）做出一个文档里没写过的功法组合，且它能赢
- 一场 PvE 斗法全程有决策点，无「闭眼点攻击」的时刻

## 9. 范围外（明确不做）

- 多人联机 / MMO（单机优先，联机留到遥远的将来再评估）
- 3D 化
- 手游化操作简化（PC 键鼠/手柄）
- 抽卡与任何形式的扭蛋
