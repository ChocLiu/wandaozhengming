# 多媒体资产清单

> 状态：初稿 v0.1 · 2026-09-02
> 用途：**按阶段明确资产需求、内容与格式要求**——美术/音频按此清单推进，不再临时起意。
> 风格方向与 AI 工作流见《视觉风格指南》；归档与命名规范见 [art/README.md](../../art/README.md)。

---

## 0. 总原则

1. **源文件进 art/（美术）与 audio/（音频），成品才进 godot/assets/**——源与成品分离，成品可随时整体替换
2. **AI 产物必须按归档规则留档**（提示词 .txt / `_ai` 后缀 / ai_generated/ 子目录）——Steam AI 披露的依据
3. **先占位后精修**：P0 阶段方块占位照常开发，资产到位即替换（内核表现分离，替换零风险）
4. 国风字体注意**商用授权**，未确认授权的字体不进成品包
5. **面板类 UI 图「内容安全区」规范（2026-09-02 定，三层）**
   - **参照规范**（公认标准，我们的取值与其对齐）：
     - **SMPTE 安全区标准**（RP 8/RP 13，2009 更新版）：文字/关键信息须位于 **Title Safe 中央 80%**（四边各 10%）内；动作内容在 Action Safe 中央 90%（四边 5%）内——「默认四边 10%」即出于此；1280×720 下 Title Safe = 1022×578
     - **Android 9-patch**：内容边距属于**图片本身**（每图自带 content region，随图走、不靠代码猜）——per-panel 缩进表的工业标准形态；Godot 对应 `StyleBoxTexture.content_margin`
     - **WCAG 2.x 对比度**：正文文字与底对比度 ≥ 4.5:1（大字号 ≥ 3:1）——纸面 UI 墨字配色遵守
     - **触控目标**：交互控件 ≥ 40px（Apple HIG 44pt / Material 48dp 的下限共识）
   - **出图规则（提示词规范，未来所有面板图遵守）**：
     - 默认：四边各 **10%** 画卷轴轴头/花边（内容不可进入）
     - **装饰占比上限：任一边 ≤ 15%**；硬性保证**内容安全区 ≥ 中央 70%×70%**
     - 类型参考值：**横幅条**——轴头 2~10%、上下装饰边 ≤15% 高；**立式卷轴/面板**——卷轴杆 10~15%、左右花边 5~10%；**按钮/小控件**——四边 ≤10%
   - **排版规则**：实际缩进按**每面板实测纸面边界+缓冲**单独定值（per-panel 缩进表，见 godot/ui/battle_hud.gd `PANEL_INSETS`）——立卷装饰在上下、横幅装饰在两端，比例天然不同；**换图只改表**
   - **留档约定**：面板图生成后量一次实测内容安全区，记入该图 .txt 留档，与代码表同步

### 1.3 音频接入与素材规范

- **接入架构（已落地）**：`AudioManager` autoload——事件 → 音效映射集中一处；SFX 池 8 路（同帧多事件不截断）；调用点散布战斗结算与 HUD，素材替换零代码改动
- **素材规范**：源 **WAV 48kHz/24bit**（留编辑余量）；成品 **OGG Vorbis q5**（≈160kbps）44.1kHz/16bit；音效 **≤2s**、峰值 **≤ -6dBFS**；参考响度：音效 **-14 LUFS**、UI 音 **-18 LUFS**、BGM **-20 LUFS**；BGM 首尾无缝、循环点无爆音
- **总线（正式版）**：Master 下分 BGM / SFX / UI 三总线，玩家可分别调音量（P0 占位期全挂 Master）
- **授权**：CC0 优先（Freesound / OpenGameArt），来源与授权记入 audio/ 随附 .txt（与 art/ 归档同规则）；AI 生成音频同样 `_ai` 后缀 + 提示词留档

### 1.4 立即可用的免费来源（备选）

- 音效：Freesound / OpenGameArt（CC0 优先）——记录来源与授权，进 audio/ 时附来源 .txt
- 字体：暂用系统字体开发，国风商用字体 P1 再定

## 4. 格式规范总表

| 类别 | 规格 |
|---|---|
| 立绘/大图 | PNG 透明底 ≥1024px（P1 正式稿 2048px）；源文件保留分层（.kra/.psd） |
| 战场精灵/特效 | PNG 透明底，64×64 / 128×128 / 256×256 网格对齐（依单位占格定） |
| UI | PNG 9-slice（四角装饰不可拉伸区明确）；图标 64×64；面板图：**出图按四边 10% 花边、排版按实测 per-panel 缩进表**（见 §0 原则 5） |
| 音频 | 源 WAV 48kHz/24bit；成品 OGG q5 44.1kHz/16bit；音效 ≤2s、峰值 ≤-6dBFS（参考响度：音效 -14 / UI -18 / BGM -20 LUFS）；BGM 无缝循环；命名 `类别_事件_变体_v序号`（见 §1.2/§1.3） |
| 3D | glTF/GLB；低模 15k~30k 三角面；卡通材质（P2 试点标准） |
| 命名 | `对象_用途_v序号.ext`（如 `主角_半身像_v3.kra`）；AI 成品 `_ai` 后缀 + 提示词 .txt（art/README.md） |
