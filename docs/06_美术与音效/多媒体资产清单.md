# 多媒体资产清单

> 状态：初稿 v0.1 · 2026-09-02
> 用途：**按阶段明确资产需求、内容与格式要求**——美术/音频按此清单推进，不再临时起意。
> 风格方向与 AI 工作流见《视觉风格指南》；归档与命名规范见 [art/README.md](../../art/README.md)。

---

## 0. 总原则

1. **源文件进 art/（美术）与 audio/（音频），成品才进 godot/assets/**——源与成品分离，成品可随时整体替换
2. **AI 产物必须按归档规则留档**（提示词 .txt / `_ai` 后缀 / ai_generated/ 子目录）——Steam AI 披露的依据
3. **先占位后精修**：P0 阶段方块占位照常开发，资产到位即替换（内核表现分离，替换零风险）
4. 国风字体注意**商用授权**，未确认授权的字体不进成品包

## 1. P0.5（当前战斗原型·立即需要）

> 目的：让原型「有样子」——斗法画面 + 基本音效反馈。全部可用 AI 铺量 + 人工精修。

### 1.1 战斗画面（图片）

| # | 资产 | 内容要求 | 格式 |
|---|---|---|---|
| 1 | 战场棋盘背景 | 10×10 格水墨山水棋盘（俯视），单格 60px（棋盘区 600×600，可外扩到 1280×720 整屏），格纹弱化、以地形纹样分区 | PNG（棋盘区不透明）；源文件分层（底色/格纹/装饰） |
| 2 | 战斗单位精灵 ×2 | 玩家（剑修，持剑）+ 散修对手（焚天诀魔道散修，狂放）；P0 只需站姿一张，后续补动作帧 | PNG **透明底** ≥128×128/格（推荐 256×256 高清）；动作帧版后续对齐 64/128 网格 |
| 3 | UI 底框套件 | 卷轴/竹简质感：解说栏底板（378×628）、信息栏底板（850×170）、按钮底板（96×36） | PNG，**9-slice 可拉伸**（切图留出四角装饰）；风格板见《视觉风格指南》概念图 #4 |
| 4 | 操作图标 ×6 | 普攻/招式/切换/防御/丹药/结束 的线描小图标 | PNG 透明底 64×64 |

### 1.2 音效与音乐（音频）

| # | 资产 | 内容要求 | 格式 |
|---|---|---|---|
| 1 | 战斗音效 ×8 | 剑击（破空+命中）、格挡/招架（金铁声）、钝击（拳）、灼烧（火势声）、服药、失血滴落、死亡（重物倒地+叹息）、回合提示音 | WAV 或 OGG，≤2 秒，单声道即可 |

### 1.3 立即可用的免费来源（备选）

- 音效：Freesound / OpenGameArt（CC0 优先）——记录来源与授权，进 audio/ 时附来源 .txt
- 字体：暂用系统字体开发，国风商用字体 P1 再定

|---|---|---|---|
| 1 | 主角立绘 ×2 | 男/女各一，半身像，持剑，含表情差分（默认/惊讶/战意） | PNG 透明底 ≥1024px（推荐 2048）；源文件 Krita/PS 分层 |
| 2 | 重要 NPC 立绘 ×3~5 | 师父、门派师兄/师姐、魔道对头——风格与主角统一 | 同上 |

## 3. P2（3D 试点 · 卡通渲染）

> 目的：验证「3D 角色 + 2D 战场」管线（《视觉风格指南》§4），通过则全面转 3D 战斗。

| # | 资产 | 内容要求 | 格式 |
|---|---|---|---|
| 1 | 试点角色模型 ×1 | 低模剑修（面数预算：15000~30000 三角面），**卡通渲染**材质（Godot toon shader） | glTF/GLB（Blender 源文件留 art/06_3D资产/） |
| 2 | 动作 ×3 | 待机 / 攻击 / 受击——Mixamo 或 Blender 自动绑定后调整 | glTF 动画或 Godot AnimationPlayer 重映射 |
| 3 | 卡通材质预设 | toon ramp + 描边参数表（可复用） | Godot 材质资源 + 参数留档 |

## 4. 格式规范总表

| 类别 | 规格 |
|---|---|
| 立绘/大图 | PNG 透明底 ≥1024px（P1 正式稿 2048px）；源文件保留分层（.kra/.psd） |
| 战场精灵/特效 | PNG 透明底，64×64 / 128×128 / 256×256 网格对齐（依单位占格定） |
| UI | PNG 9-slice（四角装饰不可拉伸区明确）；图标 64×64 |
| 音频 | WAV（源）/ OGG（成品）44.1kHz 16bit；音效 ≤2s；BGM 可无缝循环 |
| 3D | glTF/GLB；低模 15k~30k 三角面；卡通材质（P2 试点标准） |
| 命名 | `对象_用途_v序号.ext`（如 `主角_半身像_v3.kra`）；AI 成品 `_ai` 后缀 + 提示词 .txt（art/README.md） |

## 5. AI 归档红线（引用）

- 原始 AI 输出 → 各类别 `ai_generated/` 子目录 + 提示词 .txt
- 含 AI 成分的成品 → `_ai` 后缀 + 提示词 .txt（商店页披露按此清单申报）
- 无法说明来源的素材**不进游戏**（Steam 披露政策，见《Steam发行策略》§4）
