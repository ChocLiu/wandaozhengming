# 视觉风格指南

> 状态：初稿 v0.0.1 · 2026-09-01
> 决策记录（2026-09-01 拍板）：**渐进混合路线**——立绘与界面先做 2D 国风手绘（质量线：不输鬼谷八荒），P2 用 3D 卡通渲染角色试点战斗管线；**美术资产 = AI 辅助（ComfyUI）铺量 + 人工精修 + 关键内容外包**；概念图**现在启动**，与战斗逻辑开发并行。

---

## 1. 风格定位

- **主视觉**：2D 国风水墨手绘——宣纸肌理、水墨晕染、留白构图（参照鬼谷八荒的立绘与场景气质，但不照搬）
- **立绘**：关键角色全彩立绘（半身像为主，含表情差分）；路人 NPC 用通用立绘模板换装
- **战场**：2D 手绘棋盘（10×10），格纹弱化、以地形纹样与光影分区；战斗单位 2D 动画精灵（立绘风格降级版）
- **UI**：卷轴/竹简质感 + 水墨印章点缀；解说文字竖排右栏（已有布局），后续可加毛笔笔触装饰；面板图的内容安全区规则（四边装饰 ≤15%、默认 10%、排版按实测 per-panel 缩进表）见《多媒体资产清单》§0 原则 5
- **3D 试点（P2）**：战斗角色改 3D **卡通渲染**（cel-shading）——对建模精度容忍度高、适合小团队；场景 2D 背景 + 3D 角色混合构图（Persona 式）
- **色彩基调**：青黛/月白/朱砂/鎏金四色为主（仙侠水墨感），功法特效按属性配色（火朱砂红、空间青黛、金鎏金）

## 2. AI 辅助工作流（ComfyUI）

1. **概念阶段**：ComfyUI 出风格探索图/角色概念（几十张里筛方向）——不追求成品，只锁方向
2. **精修阶段**：选定概念后人工精修（PS/Krita）或重绘成正式立绘；**关键角色（主角/圣皇圣后）可外包精修**
3. **铺量阶段**：NPC/道具/场景件用 AI 批量出图 + 统一精修流程
4. **合规**：Steam 要求披露 AI 生成内容——原始 AI 输出归各类别 `art/*/ai_generated/`（随图留提示词 .txt），含 AI 成分的成品带 `_ai` 后缀+提示词留档，工作流模板集中 `art/_ai工作流/`（详见 art/README.md 与《Steam发行策略》§4）
5. **资产规格**：立绘 PNG 透明底 ≥1024px；战场精灵按 64×64/128×128 网格对齐；UI 元素切图 9-slice 可拉伸；国风字体存 `art/04_UI界面/字体/`（注意字体商用授权）

## 4. 3D 试点（P2）预研清单

- 引擎侧：渲染器切 Forward+（一键切换，代码零改动）
- 管线：低模+卡通渲染材质（Godot toon shader 内置方案）→ 绑定（Mixamo 或 Blender 自动绑定）→ 招式动画（先 1 角色 × 3 动作验证）
- 验证标准：一场战斗能跑通「3D 角色在 2D 背景战场上出招」且美术成本可控 → 通过则全面转 3D 战斗，不通过则维持 2D 精灵
