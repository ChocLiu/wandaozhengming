# 成长与经济

> 状态：初稿 v0.0.1 · 2026-08-30
> 本系统承载支柱三「世界是活的修途」与反套路宣言的核心：**没有经验条、没有金币、没有词条装备**。成长来自悟道，经济是修仙界的因果账本。

---

## 1. 反数值成长循环：悟

**没有经验值。** 成长循环是：

```
经历（战斗/游历/讲道/机缘） → 产生「感悟」 → 感悟用于推演功法与突破
```

- **感悟**：非数值化的「心性收获」。一场值得一悟的斗剑，比刷一百场杂兵更有价值
- 感悟的用途：推演功法（L2 自创）、突破三证之一、参悟功法元件（见《功法系统》）
- **反刷设计**：重复刷同一类事件，感悟收益指数衰减——游戏机制上鼓励「游历世界、经历新鲜事」而非刷怪（世界探索才是主循环）

## 2. 资源体系（无金币的修仙经济）

| 资源 | 性质 | 来源 | 去向 | 设计意图 |
|---|---|---|---|---|
| **灵石** | 通用货币，**本身是消耗品** | 矿脉/任务/斗法彩头 | 交易、战斗（布阵烧灵石、斗法烧灵力）、修炼 | 灵石在战斗中会烧掉 → 通货流动，永不贬值 |
| **寿元** | **核心张力资源** | 种族/境界/丹药 | 强力功法、突破、焚天诀类机制 | 所有「变强」的选择都有时间成本——修仙的本质是向天借命 |
| **功德/业力** | 因果账本 | 行为：救人/杀生/毁约/传道 | 影响机缘、劫数、NPC 态度 | 善恶有账，天道记账——沙盒行为的长期后果 |
| **气运** | 机缘修正 | 功德兑换、特殊事件 | 奇遇触发率、突破成功率 | 玄学变量，让世界探索有惊喜 |
| **悟性/道心** | 心性资源 | 讲道、参悟、历练 | 推演功法、抗心魔、立道 | 创作型成长的门槛（防止无限自创） |
| **人情/师承** | 社会资本 | 帮人、拜师、结盟 | 借功法、请人助阵、进秘境名额 | 修仙界是关系社会——社会资本是可玩货币 |

## 3. 寿元系统（核心张力）

- 人族凡境百年起步；突破可延寿；丹药可续命（丹修是「续命产业」——天然的经济锚点）
- **每一个变强的选择都有寿元成本**：修第二门功法、强力功法、推演自创、血魔类机制
- 寿元耗尽 ≠ 游戏结束 → 进入**死亡三途**（见下节）
- 设计目标：让「时间」成为玩家做一切决定的背景压力——你修的每一门道，都在燃烧你的命（人族的种族主题，见《种族与血脉》）

## 4. 死亡三途（死亡是内容，不是读档）

寿元尽、战死、劫数身陨时，玩家**不必读档**，而是选择（注：元婴+ 修士身死先走**元婴离体**一关，见《修炼体系》§2.2——三途是灵魂完好时的选择；元婴/元神被毁则三途皆失效，形神俱灭）：

| 途 | 转入 | 规则 | 设计意图 |
|---|---|---|---|
| **兵解** | 转器修 | 保留部分记忆与一门功法，以器灵之身继续（器族玩法入口） | 死去的角色变成新的玩法 |
| **执念** | 转鬼修 | 以执念存续，绑定一条执念任务链（鬼族玩法入口） | 死亡产生任务线 |
| **轮回** | 转世 | 转生新角色，保留「传承记忆」碎片——**可寻回前世自创的功法**（传承机制） | 自创功法永不丢失，跨世传承 |
| **形神俱灭** | 真死 | 仅当被专门针对（灵魂类攻击）时发生，可避免但有代价 | 终极失败，衬托三途的价值 |

> 联动：自创的 L3「立道」功法因轮回/兵解而传承下去，甚至可以「前世立道、今生继承」——跨世成长是独有体验。

## 5. 法宝系统（反词条装备）

> 装备的**穿戴层**（槽位结构：左右手自由/头饰耳饰颈饰分格/手指十格、储物戒「空间不嵌套」规则）见《装备系统》。

没有「刷装备」。法宝是**道的载体**：

- **本命法宝**：随境界与道途成长，具有「器灵」（性格、记忆、双向选择——器灵看不上你会拒绝认主）
- **获取**：不是掉落，而是祭炼/传承/机缘——每件法宝有一段来历（宗门至宝、仇人遗物、上古残器）
- **成长**：与你的道同修——剑修的本命剑吃「剑意」，阵修的本命罗盘吃「阵图参悟」
- **器族联动**：器族玩家的本体就是法宝（见《种族与血脉》），法宝系统与种族系统共用一个机制层
- **神器与圣器**：神族七神器（太初神殿·开天斧 + 六脉各一：诛天剑 / 宙天珠 / 鸿蒙生死印 / 五行轮 / 梵天印【未认主·待机缘】 / 星月晷）与人族三圣器（紫微剑 / 万魔幡 / 万里河山图）是法宝系统的顶点——皆有器灵（器族的巅峰存在），是终局内容位（见《世界观设定》§6.1）

## 6. 世界动态（世界是活的）

| 动态 | 机制 | 玩法影响 |
|---|---|---|
| **灵潮涨落** | 周期性世界事件（涨潮 10 年/退潮 10 年【待定】） | 涨潮：机缘井喷、秘境开启、突破更易；退潮：资源枯竭、势力洗牌、灵脉争夺战 |
| **势力兴衰** | 门派有资源、声望、道统存量，会扩张与衰落 | 玩家的站队、传道、开宗立派会真实改变格局 |
| **NPC 人生** | NPC 会修炼、拜师、突破、陨落、寻仇 | 世界不围着玩家转——你的仇人可能在你闭关时自己死了，也可能成为真境大能 |
| **功法生态** | NPC 会学习/改良/传授功法（世界功法库） | 你自创的功法可能被某个 NPC 学走、改良、开枝散叶——也可能被曲解成邪功 |

## 7. 设计红线

- [ ] 禁止「金币」：一切交易用灵石，且灵石是消耗品
- [ ] 禁止经验值与等级面板
- [ ] 禁止随机词条装备
- [ ] 任何成长必须走「经历 → 感悟 → 修炼/推演/突破」闭环，禁止杀怪直接变强
- [ ] 世界动态的事件必须可被玩家观察到（报纸/传闻系统【待定】），不可后台静默
