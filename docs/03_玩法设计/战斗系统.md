# 战斗系统

> 状态：初稿 v0.1 · 2026-08-30
> 形态：**回合制策略**（已定）。本系统是功法机制的表达舞台——每门功法在战斗中必须玩起来不一样。

---

## 1. 为什么是回合制（立项理由，存档备查）

1. **机制表达**：剑修的连击谱系、阵修的布阵、丹修的战斗炼丹、天机演的预知回卷——这些「机制完全不同」的功法，在回合制下才能充分展开；实时战斗会压缩一切机制为手速
2. **博弈本质**：斗法应当像下棋——信息、预判、规则对抗；而不是操作竞速。这符合「支柱一：道即机制」与 H4 博弈假设
3. **solo 可实现**：回合制 2D 的美术量、状态机复杂度、平衡测试成本都是个人开发可控的
4. **确定性**：便于回放、模拟自对弈、调试（技术方案见 04）

## 2. 战场框架

- **格子战场**：默认 10×10 地格（可随场景变化），单位占 1 格
- **时序条**：行动顺序**可见、可被操纵**（时序面）——操纵时序本身就是一类功法能力（加速自己、迟滞敌人）
- **回合结构**：选行动 → 结算 → 时序推进；所有机制在回合内展开（状态/资源/场地/单位/时序五面各自结算）

## 3. 战斗目标多样化（不是所有战斗都为了打死对方）

| 类型 | 目标 | 规则差异 |
|---|---|---|
| **论道** | 打掉对方「道心」而非生命 | 唇枪舌剑化为机制对抗，点到为止 |
| **斗法** | 常规击败（认输即可退出） | 争夺机缘/仲裁争端/坊市决斗 |
| **生死斗** | 击杀 | 有因果后果：对方师门寻仇、业力累积 |
| **渡劫** | 在天劫中存活 N 回合 | 天劫为敌，场地充满雷域（场地面压力） |
| **秘境** | 环境本身就是「阵」 | 破阵、解谜、生存混合目标 |
| **切磋** | 教学性目标（如「连续 3 回合维持剑意」） | 门派内教学战 |

## 4. 功法机制在战斗中的表达（对照《功法系统》）

| 功法 | 战斗中玩家实际做什么 |
|---|---|
| 青莲剑歌 | 看谱出招、管理剑意层数、预判被打断 |
| 太虚阵经 | 选地格布节点、诱敌踏阵、连锁结算 |
| 焚天诀 | 控火势蔓延方向、在烧死敌人前保命 |
| 万物生 | 种、养、收——经营一片战场生态 |
| 万鬼幡 | 指挥鬼仆走位、协同合击、防止被超度 |
| 天机演 | 花神识窥分支、决定要不要回卷一次 |
| 金石体 | 主动挨打、卡淬体进度、选择进化时机 |
| 血魔经 | 平衡吸血收益与血毒失控线 |

**验证标准**：两个玩家看完上表后，分别说「我想玩剑修」和「我想玩阵修」——若他们说不出差别，设计失败。

## 5. 信息设计（神识决定信息量）

- **信息差是战力的一部分**（呼应《修炼体系》四维）：
  - 神识低：只看到对手血量、位置、明面上的状态
  - 神识高：可见对手**功法状态**（剑意层数、淬体进度、阵图节点、血毒值）、资源面数据、甚至时序条未来
- 隐藏与识破是一对机制（藏剑意的功法 vs 勘阵术）
- UI 原则：信息分层呈现，一眼可读——回合制游戏的生命线是信息清晰

## 6. 战斗外规则

- **认输/逃跑**：任何战斗都可认输（付出代价：灵石/法宝抵押/丢面子，降声望不降因果）——支持「打不过就跑」的沙盒生存感
- **战斗消耗**：战斗烧灵石、丹药、符箓等实物资源（资源面与战斗强耦合，防止无成本刷战）
- **因果记账**：击杀/抢夺/毁约都会记入「功德/业力」账本（见《成长与经济》），NPC 会因此寻仇、疏远或敬畏你

## 7. 一局示例（设计意图演示）

> 剑修（主修青莲剑歌，辅修太虚阵经）对阵 妖修：
> 1. **开局**：妖修时序快，先手扑来；你预判其路径，在要道地格埋阵图节点（辅修机制挂载）
> 2. **中盘**：按剑谱连出三剑，剑意升至二层，解锁变招「青莲乍开」；妖修踏入阵节点，阵图连锁迟滞其身位（阵辅剑主，接口对接）
> 3. **博弈点**：剑意三层的最后一剑被妖修识破闪避——剑意溃散，你被迫转攻为守，用神识观察妖修血毒状态，判断它何时会「狂化」
> 4. **决胜**：把剑意（残余）灌入阵图，触发合击「太虚剑阵」，剑气在阵中自行运转，妖修无法突阵——你赢的不是数值，是规则

## 8. 设计红线

- [ ] 任何功法在战斗中必须有「独特的输入/决策」，禁止纯挂机被动
- [ ] 战斗时长目标：普通斗法 3~6 分钟，渡劫/论道可更长——单局不拖沓
- [ ] 每场战斗至少 2 个有效决策分支，禁止「最优解唯一」
