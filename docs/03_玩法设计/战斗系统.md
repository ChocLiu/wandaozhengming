# 战斗系统

> 状态：v0.0.5 · 2026-09-04
> 形态：**回合制策略 · ATB 进度条变体（仙剑三式）**。
> v0.0.5 核心升级：**朝向与绕后 · 部位策略制 · 流血概率化 · 护体玄气层与护体策略制 · 受伤程度链**（实机反馈四项手感轮）——绕后给走位以实利（威胁区逼近段 ×2 步罚 + 防速 ×0.7 + 招架失效），部位策略制替每击手选减负，流血概率化与受伤程度链让「见血 / 受伤」由武器数据与链式换算驱动，护体玄气成罩并按四档策略于回合末自动结算。
> v0.0.3 核心升级：**防御博弈（守势 · 招架 · 代受 · 部位化护体）**——「谁也不傻」：攻方冲要害去，守方必重点保护要害、以兵刃招架、以手臂身躯代受，除非战力差距大到根本防不住。
> v0.0.2 核心升级：**部位系统 + 无总血条 + 速度对抗 + 破防模型**——用身体结构与要害博弈替代「血条数值对撞」，这是反数值宣言在战斗层的最直接落地。

## 1. 行动方式：ATB 进度条（时序面）

- 每个单位一条**行动条**，读条速度 = **移速 × 体力修正 × 招式修正 × 状态修正**（debuff）
- 条满即行动，行动后清空——**移速快 = 读条快 = 回合多**（速度换行动次数，而不是只换先手）
- 战斗**可暂停 / 慢速**：战术思考时间，暂停中可查看全部信息（神识越高信息越全，见 §8）
- 时序面功法仍然有效：加速 / 迟滞 = 改写对方读条速度；《天机演》窥见的「未来 N 回合」= 未来 N 次行动条结算的分支

### 1.1 战场框架（最小战棋，侠客风云传式）

- **格子战场**：10×10 地格，单位占 1 格（P0 无地形障碍；高低差后置；朝向 v0.0.5 起已实装，见 §1.2）
- **回合内移动**：行动窗口内获得移动额度（步数由移速决定，走 1 格耗 1 体力；威胁区内**朝敌逼近**的格按 2 步计、横移 / 后撤仍按 1 步，额度与体力双扣）——**移动与出招顺序自由**（先走后打 / 先打后走）
- **招式射程**：攻击范围 = **招式基础射程 + 武器修正**（剑 1 格 / 枪 2 格 / 暗器 3 格，拳掌必近身但面板攻击最高）；超出射程出招无效（不消耗出招资源）
- **出招双形态**：普攻 = 随机出招（英雄坛说式）；招式面板 = 手动选招带冷却（侠客风云传式）；切换招式功法耗体力、不算出招（主修玄术不可切换）
- **走位博弈**：远程放风筝、近身贴身短打、卡位截断退路——距离本身是一种资源

**威胁区走位惩罚（v0.0.5 实装）**：
- **威胁区** = 以敌人为中心、chebyshev 距离 ≤ (1 + 武器射程修正) 的格子（剑 / 空手 = 半径 1 格、枪 = 2 格）；**武器脱手时**按空手（半径 1）计——破格挡打落兵刃，顺带收缩对方威胁区
- **步价方向化**（v0.0.5 口径修订）：区内**朝敌逼近**（新格距敌较原格更近）的格子计 **2 步**；区内**横移 / 后撤**（距敌不变或变远）计 **1 步**；区外恒 1 步——步数额度与体力按实际步数双扣。正面扑脸的逼近段付 ×2 费，贴敌绕弧与抽身不罚——**威胁步惩罚防的是白嫖正面突进**
- 移动可达性与 AI 逼近统一用**带权最短路**（按方向化步价：普通格 / 横移后撤格权 1、朝敌逼近格权 2）判定，取代曼哈顿直跳；玩家回合可移动高亮区中，威胁格仍以**淡红框**标出（威胁区判定本身不变，见上）
- 战术落点：贴敌绕弧不付 ×2 费——**绕后缩成一回合承诺**（贴着刀锋绕 180° 斜弧到正后约 3 步，守势步数恰好够，绕弧与逼近分账清晰）；「撤退吃药」的抽身同样不被威胁费拖累（与 AI 小撤退创造的绕后窗口互为表里，见 §1.2 / §6.2）

### 1.2 朝向与绕后（v0.0.5 实装）

朝向拆成**视觉**与**几何**两个概念，共用一套移动模型：

**视觉朝向 vis_facing（贴图朝向，±1）**
- 出动作（出招或受击）前，若双方 **x 坐标不同则翻转面朝对方**；同一纵轴（x 相同）保持上一步朝向不变；移动结束后若末步**水平位移非 0**，也按该方向更新朝向
- 绘制：贴图统一按「面朝右」出图，引擎按 vis_facing 做**水平镜像**（`SPRITE_DIR` 常量控制正反向——试玩发现镜像反了只改这一常数，**不动资产**）；美术出图规范见《多媒体资产清单》§0，后续帧动画 / 立绘同理

**几何背向 geo_facing（绕后判定的依据）**
- geo_facing = **最近一次移动最后一步的方向**（Vector2i）；本回合未移动则为 (0,0)——**没有背的单位不可绕**
- 未移动时视觉上仍面朝对手（视觉规则），几何上却无背——**守势龟缩 = 不可绕，但交出走位主动权**（被磨防 / 被拉距只能吃下）

**绕后判定**（攻击者 a → 守方 d）：`d.geo_facing ≠ (0,0)` 且 **(d 位置 − a 位置) · d.geo_facing > 0**——攻击者位于守方来路的对侧（身后）即算绕后

**绕后效果**
- ① 被绕后者**防速 ×0.7**（`FLANK_SPEED_MULT`）——更易命中
- ② **招架层不再判定、守势集中护体乘区失效**——背后看不见来剑（§5.1.3 / §5.1.5）
- ③ **代受保留**——本能反应，无需「看见」（§5.1.4）
- 全程配解说文案；数值为初值，待手感调参

**在 1v1 中的意义与反制**：绕后的猎物 = **上一回合移动过的人**——追击杀退 / 风筝中的对手天然有背；AI 重伤小撤退（§6.2）正是给玩家创造真实绕后窗口

## 2. 部位系统（⑥ 部位面）

### 2.1 身体分解

每个单位（按种族 / 境界有差异）分解为部位：

| 区域 | 部位 | 受伤后果示例 |
|---|---|---|
| 头部 | 眉心（识海）、天灵、面门、咽喉 | 识海毁=神识全失；天灵受创=神志昏聩 |
| 胸腹 | 胸膛、丹田、腰腹 | 丹田毁=道基尽毁；胸创=失血 |
| 手足 | **左臂、右臂、双腿**（v0.0.3 拆分，独立状态机） | 臂伤=攻击/招架/施法受损（按功法而定）；腿伤=移速身法大减——伤效映射见 §2.5 |

- **攻击可选部位**；**防御可选重点部位**（集中防守：该部位防御速度与强度↑，其余部位↓）+ 敏捷（整体反应速度）——守势宣言详见 §5.1
- 红线：部位是**状态机**，不是「每个部位一条血条」——禁止把部位做成第二套 HP

### 2.2 部位状态机

完好 → 轻伤（功能减弱）→ 重伤（功能丧失）→ 毁（不可逆）

### 2.3 失血（v0.0.5：流血概率化）

- 未处理的创伤流失**气血**；止血（丹药 / 功法 / 包扎 / 烧灼）可止流失
- **失血按回合结算**（该单位行动时扣一次），不按实时——暂停思考 / 挂机不会流血而死（灼烧等持续状态同理）
- **「一直打对手手臂，只要对方有止血方法，就不会再掉气血」成立**——部位伤害与总血量解耦
- **是否流血 = 掷流血骰**（v0.0.5 替换旧「必流血」规则）：受伤（部位状态升为轻伤及以上）后掷骰，入血概率 p = min(1, EDGE_P[edge] × BLADE_MULT[blade] × SEV_MULT[部位最终状态])——掷骰走**战斗内确定性 RNG**（`--seed` 注入可回放复现，确定性内核红线）

武器基本属性新增两维（weapons 数据层，随兵器归档）：
- **edge 锋利度** 0~3：0 钝 / 1 半刃 / 2 利刃 / 3 纯刃
- **blade 刃长** 0~2：0 短 / 1 中 / 2 长

概率系数表（初值，待实机手感调参——只动常数不动结构）：

| edge 锋利度 | EDGE_P | blade 刃长 | BLADE_MULT | 部位最终状态 | SEV_MULT |
|---|---|---|---|---|---|
| 0 钝 | 0.10 | 0 短 | 0.75 | 轻伤 | 0.6 |
| 1 半刃 | 0.45 | 1 中 | 1.00 | 重伤 | 0.85 |
| 2 利刃 | 0.75 | 2 长 | 1.15 | 毁 | 1.00 |
| 3 纯刃 | 1.00（必流） | — | — | — | — |

**兵器归档（P0）**：

| 武器 | edge | blade | 说明 |
|---|---|---|---|
| 空手 | 0 | 0 | 钝 + 短——拳脚打出伤口大多不流 |
| 剑 | 3 | 2 | 纯刃 + 长——打中轻伤也可能必流 |
| 枪 | 1 | 2 | 半刃 + 长 |
| 拳套带刃等其它 | — | — | 后续按 edge / blade 两维归档（初值待调） |

结论性描述：**纯刃（刀剑）打中轻伤也可能必流；棍棒拳脚（钝）打出伤口大多不流**——兵器流派差异从数据层体现，而非写死代码分支。

### 2.4 要害（境界决定，见《修炼体系》§2.1）

- 击毁要害 = **一击毙命**（或道基尽毁——比死更惨）
- 要害攻击高收益，但**命中门槛更高**（要害部位的速度对抗有惩罚），且防御方会重点保护
- 境界上升 = 要害收敛转移（凡人处处命门 → 化神只剩元神）——高境界怕的不是物理攻击，是神魂攻击

### 2.5 部位伤效（臂腿伤 → 功能修正）

> v0.0.3 新增。要旨：**受伤不只是掉血**——手臂、腿的伤势直接改写攻防能力；具体伤什么，由**功法的手臂依赖声明**决定（数据驱动，接口纪律）。

**部位结构 v0.0.3**：「手足」拆分为**左臂 / 右臂 / 双腿**三个部位（各自独立状态机，见 §2.2）；单位声明**主用臂**（惯用手，默认右臂）。三层境界的部位结构同步拆分（《修炼体系》§2.1，代码层 REALM_BODIES）。

**功能域**：攻击力 / 招架值 / 身法（敏捷·闪避）/ 招式熟练度（临时降档）/ 移动步数——五种。

**伤档修正表**（部位状态 → 功能修正，统一由 BodySystem 维护）：

| 部位状态 | 攻击力 | 招架值 | 身法 | 熟练度（临时） | 移动 |
|---|---|---|---|---|---|
| 轻伤 | ×0.7 | ×0.7 | ×0.8 | 按低 1 档称号计算 | 步数 -1（腿） |
| 重伤 | ×0.4 | ×0.4 | ×0.5 | 按低 2 档计算 | 步数减半（腿） |
| 毁 | 依赖此臂的招式禁用 | 禁用 | ×0.3 | — | 无法移动（腿） |

**功法手臂依赖声明（arm_usage）**——每门功法声明双臂各影响哪些功能域：

| arm_usage | 说明 | 主用臂伤 | 非主用臂伤 |
|---|---|---|---|
| 单臂持械 | 剑、刀等单手兵刃 | 攻击 + 招架 | **无影响** |
| 双臂持械 | 枪、重剑、弓等双手兵刃 | 攻击 + 招架 | **攻击 + 招架** |
| 双拳 | 拳脚，双手各半 | 攻击 | 攻击（减半幅度） |
| 副手结印 | 主臂持器、副臂掐诀（玄术） | 攻击 + 招架 | **招式熟练度临时降档** |
| 副手护身 | 副臂主防（招架类功法） | 攻击 | **招架** |
| 身法借力 | 手臂参与平衡借力（身法类） | 攻击 + 招架 | **身法** |

**双手兵刃硬规则**：双臂持械功法中声明「需双臂」的招式，任一手臂**重伤或毁 → 立即禁用**（无法施展需要此手臂的攻击、招架）；轻伤仍可施展，只是攻防修正。

**换手**（主用臂被毁的挽救）：
- 主用臂毁 → 副臂转为主用臂，主臂伤效套用到新主臂
- 换手惩罚：副手生疏——攻击/招架额外 ×0.8（P0 固定值；后续可设计「左剑专精」类功法消除惩罚）
- 双臂皆毁 → 只能施展「心念发动」类招式（不需手臂）或逃跑

**腿部伤效**：轻伤步数 -1、身法 ×0.8；重伤步数减半、身法 ×0.5；毁 → 无法移动、身法 ×0.3——腿伤经「移速（读条）」与「身法（闪避/代受反应）」双通道影响战局。

**境界钩子**：招式声明 `需手臂` 档位（0 心念发动 / 1 单臂 / 2 双臂）——玄术默认需结印（1），**元婴+ 可修「心念发动」变体（0）**：境界越高对肉身的依赖越低，与「高境界怕神魂不怕物理」同主题（P1+ 内容位，数据位 P0 留好）。

**联动**：攻击力修正 → 破防模型（§5）；招架值修正 → 招架对抗（§5.1.3）；身法修正 → 速度对抗（§4）与代受反应（§5.1.4）；熟练度降档 → 招式威力系数（见《功法系统》§2.2）。
**红线**：伤效是**乘区 + 禁用**的机制修正，修正表统一由 BodySystem 维护——禁止各功法自写一套伤效逻辑。

### 2.6 元婴离体与夺舍（高境界的死亡博弈）

- **元婴态**：元婴+ 单位肉身死亡（失血 / 要害毁）时，不立即死亡——元婴遁出，进入**逃亡窗口**（P1+：元婴为高速小单位，N 回合内逃出战场边缘或安全格即存活）
- **反制**：神魂招法 / 寂灭类机制可击杀元婴——肉身死不是结束，**追杀元婴**是高境界战斗的第二阶段
- **夺舍**：元婴态可尝试夺舍低境界单位——神魂对抗判定（魂力 / 规则粗分阶），成功 = 接管其肉身（面板随之），失败 = 元婴反噬受损；**业力重罚**记入功德/业力
- 玩法落点：「杀金丹只需一剑，杀元婴要赢两次」——境界差 = 战斗规则差（P1 后置，数据位已留）

## 3. 无总血条：战斗四池（资源面）

**没有总体血条**，只有四个战斗资源池：

| 池 | 含义 | 归零后果 | 主要来源 / 消耗 |
|---|---|---|---|
| **气血** | 生命之血 | **失血而死** | 创伤持续流失 / 丹药、止血回补 |
| **体力** | 行动体能 | **力竭**（无法行动） | 招式身法消耗 / **<50% 速度渐慢** |
| **玄力** | 术法之力 | 无法施法 | 玄修功法消耗 |
| **魂力** | 神魂之力 | **神魂消散**（高境界真死途径） | 神魂功法 / 神识消耗 |

**三种死法对应三种策略**：磨血（放血耗死）/ 狙击（一击毁要害）/ 灭魂（神魂攻击）。死亡判定与「死亡三途」衔接（见《成长与经济》）。

## 4. 命中结算：速度对抗 + 规则对抗

- **速度维度**：攻击总速度 = 移速 + 敏捷 + 招式速度加成 ± 状态修正；防御总速度 = 移速 + 敏捷 + **招架侧重**加成 ± 状态修正
- 攻 > 防 → **命中**；攻 ≤ 防 → **招架 / 闪避**（防御方消耗体力）
- **规则维度（悟道之力）**：攻击方可**融入规则之力**（消耗玄力），防御方同样可融入反制——**即使动作没有对方快，只要规则领悟碾压对方，依然可以击中**（见 §4.1）
- 判定流程：速度胜 → 命中；速度败但规则差「碾压」（差 ≥ 一阶）→ 仍命中；速度败且规则被反制 / 持平 → 招架
- **高级身法招式**：速度加成大，但消耗更多体力 / 玄力——**用资源买速度**
- 部位影响：腿伤降移速、手伤降攻击速度；debuff（迟滞 / 迟缓 / 剑意溃散）参与修正
- 体力低于 50%：速度逐渐变慢（疲惫惩罚）——控体力 = 控速度 = 控回合
- **本判定只是防御链的第一层（身法闪避）**——闪避之后还有招架 / 代受 / 护体三层，见 §5.1 防御博弈

### 4.1 规则之力（悟道的战斗化）

- 悟道产出**道力**与**规则之力**（见《修炼体系》§2.5），规则领悟分阶：初窥 → 明悟 → 小成 → 大成 → 掌道
- **融入规则**：攻 / 防时主动融入已领悟的规则（消耗玄力）——规则差修正命中，法则给予属性加成；**差 ≥ 一阶 = 碾压**：速度上输了也能靠规则命中
- 法则属性加成（机制级，非数值）：

| 法则 | 攻击融入加成 | 防御融入加成 |
|---|---|---|
| 空间 | 命中修正（隔空锁定） | 闪避修正 |
| 时间 | 读条修正（时序面） | 迟滞对手读条 |
| 火 | 灼烧（状态面） | 焚尽来袭之物 |
| 水 | 渗透连绵（状态面） | 卸力 |
| 金 | **锋锐**——破防加成 | 坚壁 |
| 木 | 缠绕束缚 | 愈伤 |
| 土 | 重压（迟滞） | 厚重防御 |
| 风 | 速度加成 | 卸劲 |
| 雷 | 麻痹（读条迟滞） | 感电反震 |
| 因果 | 命中修正（定业） | 业力偏转 |
| 寂灭 | 部位毁坏倾向 | 寂灭护体 |
| 轮回 | 【待定】 | 【待定】 |

- 红线：规则领悟是**层级**不是面板数值；加成是**机制**（状态 / 破防修正 / 时序），不是「攻击力 +X%」

## 5. 破防模型

- v0.0.5 数值模型：破防判定只对比攻击与单位**静态防御 armor**（P0 按境界取值，受守势集中 / 放空的部位乘区影响，见 §5.1.5）；**护体玄气与肉身强度不是 armor 的组成部分**，而是破防之后的缓冲与衰减——罩在 armor 之外（§5.1.5）、肉身强度在受伤程度链里二次衰减（§5.3）
- 攻击力 vs 防御（armor），三种结局：

| 对比 | 结果 |
|---|---|
| 攻击力远低于防御 | **无伤**（打不动） |
| 攻击力略低 / 接近防御（ap ≤ armor 且接近） | **磨防**——armor −4（只磨装备防御，久攻必破） |
| 攻击力高于防御（ap > armor） | **破防** → 先扣护体玄气罩：罩足 = 「护体受震」无伤无创伤；罩尽 → 余量进受伤程度链（§5.1.5 / §5.3） |

- **要害攻击绕过装备防御**（直取命门，不看装备——但命中更难）→ 高防御重甲角色的天敌
- 防御侧重：把防御资源集中到重点部位，其余部位放空——防御本身也是博弈（守势集中的 armor 乘区见 §5.1.2 / §5.1.5；护体罩 P0 为全局单罩，部位化 P1）

### 5.1 防御博弈：守势 · 招架 · 代受（v0.0.3 核心新增）

> 要旨：**谁也不傻**——击杀对手一定冲要害去，所以守方一定重点保护要害、以武器招架，甚至以手臂或身躯代受，除非战力差距大到根本防不住。防御不是全局旗标，而是**部位级的主动博弈**。

#### 5.1.1 防御四层（由外到内，攻击依次穿透）

| 层 | 手段 | 性质 | 判定 | 代价 |
|---|---|---|---|---|
| ① 身法闪避 | 挪腾躲闪 | 被动常驻 | 速度对抗（§4 现模型） | 无（速度劣势则形同虚设） |
| ② 武器招架 | 兵刃格挡攻击点 | 主动（守势覆盖） | 招架对抗（§5.1.3） | 耗体力、武器耐久；有招架上限 |
| ③ 代受 | 肢体/身躯硬接 | 主动（自动触发） | 反应对抗（§5.1.4） | 代受部位直接受伤（可能毁） |
| ④ 护体玄气 | 装备 armor 硬抗 + 玄气罩（罩在 armor 之外） | 被动（P0 全局单罩） | 磨防 vs armor（§5）；破防先扣罩（§5.1.5） | 被磨防则 armor −4；破防耗罩，罩尽余量进受伤链（§5.3） |

- 攻击结算顺序：**闪避 → 招架 → 代受 → 护体**，任何一层成功，其后各层不再发生
- 前三层是「防」，第四层是「挨」——设计意图：**同阶对决很难一招见血**；见血靠打空当、破格挡、磨防或规则碾压

#### 5.1.2 守势宣言（防御方每回合的决策）

- **宣言时机**：防御方在**自己的回合**宣言守势，**保持到主动更改**（不占出招机会，宣言即生效）；**开战时双方先各宣言一次初始守势**（战前对峙，无需消耗）
- **重点保护部位 1~2 个**：守势集中——该部位有效防御（armor 乘区）↑、其余部位放空↓（护体罩本身不分部位，见 §5.1.5）；此部位被攻击时自动进入**招架对抗**；**被绕后（§1.2）时集中乘区失效**——背后看不见来剑
- **架势三选**：
  | 架势 | 效果 | 代价 |
  |---|---|---|
  | 招架架势 | 武器格挡，招架判定加成最大 | 本回合机动受限（移动步数 -1） |
  | 闪避架势 | ①层闪避判定加成 | 消耗体力 |
  | 铁壁架势 | ④层 armor 乘区集中加强（被绕后失效，§1.2） | ①层闪避判定下降——赌「猜中部位」 |
- **无守势**（未宣言或体力不足）：只剩 ①④ 两层——高危状态
- **设计核心**：守势在自己回合设、管到下次行动——守方永远在**猜下一击**，攻方永远在**观察守势再出手**（神识越高看得越清，§8）

#### 5.1.3 招架对抗（②层）

- 触发：攻击部位 ∈ 守方重点保护部位，或守方处于招架架势；**只对物理招式生效**（兵器/拳脚）——玄术/神魂无实体可格，直穿②层（v0.0.3 实现修订）
- **绕后与招架（v0.0.5）**：攻方已绕到身后（§1.2）时守方看不见来剑——②层**不再判定**（无论是否重点保护 / 招架架势），守势集中乘区同步失效（§5.1.5）；**代受（③）保留**（本能反应）
- 判定：攻方「力量 + 速度」vs 守方「武器招架值 + 架势加成 + 敏捷」
- 武器招架值由兵刃类型决定：**剑高、枪中、拳/空手最低**（拳修靠身法闪避而非格挡）；招架值有**上限**（境界 + 武器品质）
- 结果：
  - **招架成功**：完全抵消，守方耗少量体力
  - **招架失败 → 破格挡**：攻击穿到下一层；守方武器耐久 -1（耐久归零 = 武器损坏）
  - **碾压破格挡**：攻击力超出守方招架上限 → **武器脱手**（守方武器面板暂时失效，须花一回合拾回【P1】）
- **战力差距阶梯**（「根本防不住」的量化）：
  - 同阶：防御链完整，招架/代受有效
  - 差一阶（境界或规则粗分阶）：招架必破——②层跳过
  - 差两阶以上（realm_d ≥ 2）：护体玄气虚设直接穿透、肉身衰减无视（§5.1.5 / §5.3）——破防余量直入受伤链，伤档**保底重伤**（max(severity, 2)）

#### 5.1.4 代受（③层）

- 触发：攻击已越过①②，目标是**要害**，且守方存在可用代受部位
- **可用代受部位**（非致命部位换要害）：手臂 → 代受头部/心脉/眉心神识；肩背/胸腹 → 代受丹田
- 判定：守方反应（敏捷 × 体力修正）vs 攻方速度——**差距大 = 来不及代受**
- 结果：代受成功 = 攻击改落在代受部位上（按破防模型结算，**可能被打到毁**）；代受部位已毁 = 无法再代受
- 设计意图：**代受是消耗战**——守方用手臂换命，但手臂毁 = 攻击力骤降；攻方故意强攻要害逼对方代受，本身就是「远程磨掉对方手臂」的策略
- 元婴+：要害收敛（《修炼体系》§2.1），可代受部位减少——高境界代受更难，对应「境界高不怕物理、怕神魂」

#### 5.1.5 护体玄气罩层与守势集中（④层 · v0.0.5 实装修订；部位化 P1）

**罩层（v0.0.5 实装，位于 armor 之外）**
- 磨防照旧磨 armor（ap ≤ armor 且接近时 armor −4，见 §5 三态表）；**破防（ap > armor）→ 先扣罩**：absorb = min(护体罩当前值, ap − armor)
  - 罩足 → 「护体受震」：**无伤、无创伤**（淡金波纹 fx + 解说 + 「护体」低音）
  - 罩尽 → 余量（net2）进受伤程度链（§5.3）
- **罩上限** = 境界基数（凡人 15 / 练气 30 / 筑基 45 / 金丹 60）+ 功法挂载 `bonus_shield`（青莲心法 +15、焚天诀 +10，见《功法系统》§2）+ 修为称号档 ×2/档（称号每 5 点一档）；**开局满罩**（对峙先互相轰罩）
- 罩**首次归零**解说一次「护体告破」（破罩音 + 崩裂 fx），此后不再重复；罩的补充与维持走**护体策略制**（§5.2）
- **境界压两级以上（realm_d ≥ 2）护体虚设**：罩直接穿透（旧「差两阶 + 护体虚设」规则保留，见 §5.1.3 战力差距阶梯）
- 注：**P0 实装为全局单罩**（不分部位）；**部位化护体（罩分布在各部位、逐部位磨防与告破）后置 P1**——本轮数据位已留，只动常数不动结构

**守势集中（v0.0.5 修订）**
- **有效防御 = 基础 armor ± 守势集中 / 放空乘区**（按部位）：守势「重点保护」（§5.1.2）把 armor 乘区加在重点部位、其余部位放空——磨防与破防围绕部位轮转，仍是博弈重心
- 要害攻击绕过装备防御的旧规则保留，但守势集中时该部位**不再是裸的**（集中乘区 + 自动招架可接）
- **被绕后（§1.2）时集中乘区失效**——看不见来剑，重点部位回归裸奔（招架亦不判定，§5.1.3）

#### 5.1.6 决策空间总结

| 局面 | 攻方选择 | 守方应对 |
|---|---|---|
| 守方重点保护头部 | 打空当（手足/胸腹——易中但非要害） | 轮转保护 / 吃下非致命伤 |
| 攻方强攻要害 | 赌破格挡 / 逼代受（磨掉对方手臂） | 招架 + 代受双保险，烧体力 |
| 相持不下 | 磨防、耗对方体力（招架耗体力 → 累则慢 → 破绽） | 找机会脱离 / 反击【反击机制后置】 |
| 战力碾压 | 无脑强攻——守方一切防护形同虚设 | 逃——认清局势也是策略 |

- **红线**：招架/代受是**机制层**判定，禁止做成「格挡率 X%」式纯概率——判定全部由 力量/速度/规则 对比驱动，确定性内核可回放

### 5.2 护体策略制（v0.0.5 实装）

罩的补充不再每回合手点——单位挂一档**护体策略**，回合末按档自动结算一次：

| 档 | 措辞 | 行为 | 回合末结算 |
|---|---|---|---|
| 维持 | **守常** | 玄气循常运转，不主动灌注 | 只付维持费，不补罩 |
| 回满（100%） | **周天** | 行小周天搬运，护体回满 | 补至 100%（罩内 1 玄力 : 1） |
| 加强（125%） | **凝罡** | 凝气成罡，护体超常 | 补至 125%；超出 100% 部分按 1.25×/点 |
| 专注（150%） | **守一** | 抱元守一，全力倾注 | 补至 150%；100~125% 段 1.25×、125~150% 段 1.5×/点（先填低价段） |

- **择档时机**：自己行动窗口内随时宣言——出招后 / 移动后亦可（宣言制，同守势 / 丹药）；**改档后不立即结算**
- **结算时机**：本回合结束时（AI 同一出口）按所选档补罩一次，**先于对手行动生效**；结算后档位保持，下回合默认沿用，直到再改
- **档位持久**：档挂在单位上，跨回合沿用——**不强制每回合重选**
- **择低档不放气**：罩高于新档目标时不衰减、不退款——超量留存到被击消耗或再抬档（防「反复充值套利」；也保留「守一后罩厚多扛几回合」的余韵）
- **维持费**：罩 > 0 时每回合行动开始扣 1 玄力（四档同付）；**玄力空则免扣、罩不衰减**；玄力不足时结算按可支付额**部分补罩**
- 择档 / 回合末补罩配「凝护」音；单位行显示「罩 cur/max（策略名）」（音效见《多媒体资产清单》§1.2）
- 罩上限构成与受击分配见 §5.1.5；AI 的档位决策见 §6.2

### 5.3 受伤程度链（v0.0.5 实装，替换固定伤档）

受伤不再按「破防即固定 severity」定档——破防余量走**链式换算**，全部数值为初值，只动常数不动结构：

> 破防余量 net（= ap − armor，守势集中乘区已在前段体现）→ **扣罩后余量 net2** → **肉身强度二次衰减** net3 → 按 r = net3 ÷ 对方气血上限定档

- **肉身强度二次衰减**：net3 = net2 × (1 − FLESH_ABSORB[境界])；境界压两级以上（realm_d ≥ 2）**无视肉身衰减，直接穿透**

| 境界 | FLESH_ABSORB（肉身衰减率） |
|---|---|
| 凡人 | 0.15 |
| 练气 | 0.20 |
| 筑基 | 0.24 |
| 金丹 | 0.28 |

- **对气血比例定档**：r = net3 ÷ 对方气血上限

| 伤档 | 定档条件 |
|---|---|
| 轻伤（severity 1） | r < 0.08 |
| 重伤（2） | r < 0.18 |
| 毁（3） | r ≥ 0.18 |

- realm_d ≥ 2 时伤档**保底重伤**：max(severity, 2)（旧「战力差距伤害加深一档」的底线化保留，§5.1.3）
- 伤害档累进既有**部位状态机**不变（完好 → 轻伤 → 重伤 → 毁，§2.2）；毁则循例走要害击毁 / 代受 / 换手处理（§2.4 / §5.1.4 / §2.5）
- 灼烧等既有分支不动；伤档阈值与衰减率均为初值，待实机手感调参——只动常数不动结构

## 6. 回合内选择（策略组合空间）

每回合可选：

| 行动 | 决策点 |
|---|---|
| 攻击 | 选招式 × **出招部位策略**（自动 / 随机 / 手动 / 重点，§6.1）：速度加成 / 资源消耗 / 部位倾向的权衡 |
| 守势宣言 | 选重点保护部位 1~2 个 + 架势（招架/闪避/铁壁），持续到下次行动（§5.1） |
| 护体策略 | 守常 / 周天 / 凝罡 / 守一 择档——行动窗口内随时宣言（不占出招），本回合末自动结算（§5.2） |
| 身法 | 走位、闪避，耗体力 / 玄力 |
| 功法机制 | 各道核心循环（剑谱连击 / 布阵 / 炼丹……） |
| 融入规则 | 选已领悟法则注入本次攻防（消耗玄力）——规则对抗修正命中 + 属性加成 |
| 物品 | 止血丹药、符箓——**丹药每回合每种限用一次，不占攻防行动次数**（不同丹药可各自使用） |
| 认输 / 逃跑 | 体面收场，付出代价 |

策略循环 = **读条速度管理 × 部位选择 × 四池资源 × 破防 / 要害博弈**——这正是「道即机制」在战斗层的表达。

### 6.1 出招部位策略制（v0.0.5 实装）

出招**不再每击强制手选部位**——普攻 / 选招后按当前策略直接出手，部位选择由「策略」承担：

- **自动**：复用 AI 选部位的确定性版优先序——未守势要害 → 未守势部位 → 胸腹兜底（去掉随机，双方公平同源）
- **随机**：存活部位任选
- **手动**：保留旧流程——出招后弹部位行亲手点选（「每击手选」的旧能力仍在）
- **重点**：先从部位行点选锁定敌方**一个部位**（按钮显示「重点 · 部位名」），此后自动专攻该部位；该部位**被打毁自动退回「自动」**并解说（长时间磨一个部位的战术）
- HUD 底部有循环按钮在四态间轮换（标签随状态变），不弹新面板、不打断操作流；仅「手动」态出招后才弹部位行
- AI 不受影响（本就不弹 UI）——AI 的部位选择恒走「自动」策略

### 6.2 AI 对手的行为（v0.0.5 实装，与玩家同规则）

- **护体策略**：默认守常；若**玄力过半且罩低于上限** → 本回合改「周天」补满（档位持久沿用，回合末同出口结算，§5.2）
- **小撤退**：气血 < 35% 且正在流血且体力 > 40 → 拉开 2~3 格（后撤横移按 1 步计、不受逼近 ×2 罚）吃药、本回合不出手——**给玩家真实绕后窗口**（§1.2）
- **绕后尝试**：射程内约 30% 概率先绕到守方身后再出招（自对弈统计可验证 flank 数据）
- **逼近 / 走位**：用带权最短路（按方向化步价：仅朝敌逼近格 ×2，横移 / 后撤 1 步，§1.1）
- 出招部位选择 = 确定性优先序（与玩家的「自动」策略同源，§6.1）

## 7. 功法机制在战斗中的表达（对照《功法系统》）

| 功法 | 战斗中玩家实际做什么 |
|---|---|
| 青莲剑歌 | 按剑谱序出招打**部位**（咽喉、手腕优先），管理剑意层数（壹/贰/叁）：破防命中连击升层 → 释放变招（青莲乍开抢速 / 剑意如丝破代受）或叁层赌大招（青莲怒放，出招即倾尽剑意）；被闪避 / 被招架则溃散重来（v0.0.4 已实装，数值见《功法系统》§3） |
| 太虚阵经 | 选地格布节点、诱敌踏阵、连锁结算 |
| 焚天诀 | 控火势蔓延方向，在烧死敌人前保命 |
| 金石体 | 主动挨打（受击成长），卡淬体进度，选择进化时机 |
| 妖灵契 | 与妖灵共战，管理灵魂力与灵约 |
| 天机演 | 花魂力窥分支，决定要不要回卷一次 |

**验证标准**：两个玩家分别说「我想玩剑修」「我想玩阵修」——若说不出差别，设计失败。

## 8. 信息设计（神识决定信息量）

- 神识低：只看到对手位置、明面上的状态、四池大致
- 神识高：可见对手**部位状态、要害位置、防御侧重、读条进度**——信息差是战力的一部分
- 隐藏与识破是一对机制（藏剑意的功法 vs 勘阵术 vs 神察）

## 9. 一局示例（设计意图演示）

> 剑修（青莲剑歌）对阵 金丹期妖修：
> 1. **开局对峙**：双方宣言守势——你重点保护「咽喉」、剑作招架架势；妖修重点保护「丹田」
> 2. **开局**：妖修移速快，行动条先满，扑向你咽喉（打人族命门）——你的剑堪堪**格挡**（招架成功，它白耗体力）；它第二回合学乖，改攻你放空的手腕——这一下它得手，你手腕轻伤
> 3. **中盘**：你连出剑谱三剑，前两剑打它的手（卸其兵刃，降它攻击速度），第三剑刺它小臂——**创伤持续失血**；它吞丹药止血（失血止，但浪费了一回合）
> 4. **博弈点**：妖修发现你的剑意已至二层，不敢恋战，开始磨你**胸腹部位的防御**（你守势不在胸腹——该部位 armor 无集中乘区，它在等磨穿破防先耗你护体罩）；你决定抢先：赌一记「高级身法·青莲乍开」，速度加成巨大但耗体力过半（体力惩罚开始逼近）
> 5. **决胜**：这一剑**绕过装备防御直取它丹田**（打金丹！）——丹田正是它的重点保护部位，它来不及变招，**手臂一横代受**——小臂被斩落，丹田保住；你剑势一变，**融入空间规则**（玄力见底也在所不惜）锁定它的眉心神识——它的代受部位已毁、无可代受，速度再快也躲不开这一剑——识海重创，妖修魂力归零，**神魂消散**
> 赢的不是数值，是守势博弈、部位博弈、招架与代受的资源消耗组合

## 10. 设计红线

- [ ] 禁止总体血条回归：战斗胜负必须由失血 / 要害 / 神魂三途径判定
- [ ] 部位是状态机，禁止部位血条化
- [ ] 规则加成禁止数值化：法则加成必须是机制（状态 / 破防修正 / 时序），禁止「攻击力 +X%」
- [ ] 任何功法必须有「独特的输入 / 决策」，禁止纯挂机被动
- [ ] 战斗时长目标：普通斗法 3~6 分钟，渡劫 / 论道可更长
- [ ] 每场战斗至少 2 个有效决策分支，禁止「最优解唯一」
