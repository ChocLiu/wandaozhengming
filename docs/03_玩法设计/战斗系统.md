# 战斗系统

> 状态：初稿 v0.3 · 2026-09-02
> 形态：**回合制策略 · ATB 进度条变体（仙剑三式）**。
> v0.3 核心升级：**防御博弈（守势 · 招架 · 代受 · 部位化护体）**——「谁也不傻」：攻方冲要害去，守方必重点保护要害、以兵刃招架、以手臂身躯代受，除非战力差距大到根本防不住。
> v0.2 核心升级：**部位系统 + 无总血条 + 速度对抗 + 破防模型**——用身体结构与要害博弈替代「血条数值对撞」，这是反数值宣言在战斗层的最直接落地。

---

## 1. 行动方式：ATB 进度条（时序面）

- 每个单位一条**行动条**，读条速度 = **移速 × 体力修正 × 招式修正 × 状态修正**（debuff）
- 条满即行动，行动后清空——**移速快 = 读条快 = 回合多**（速度换行动次数，而不是只换先手）
- 战斗**可暂停 / 慢速**：战术思考时间，暂停中可查看全部信息（神识越高信息越全，见 §8）
- 时序面功法仍然有效：加速 / 迟滞 = 改写对方读条速度；《天机演》窥见的「未来 N 回合」= 未来 N 次行动条结算的分支

### 1.1 战场框架（最小战棋，侠客风云传式）

- **格子战场**：10×10 地格，单位占 1 格（P0 无地形障碍；高低差、朝向后置）
- **回合内移动**：行动窗口内获得移动额度（步数由移速决定，走 1 格耗 1 体力）——**移动与出招顺序自由**（先走后打 / 先打后走）
- **招式射程**：攻击范围 = **招式基础射程 + 武器修正**（剑 1 格 / 枪 2 格 / 暗器 3 格，拳掌必近身但面板攻击最高）；超出射程出招无效（不消耗出招资源）
- **出招双形态**：普攻 = 随机出招（英雄坛说式）；招式面板 = 手动选招带冷却（侠客风云传式）；切换招式功法耗体力、不算出招（主修玄术不可切换）
- **走位博弈**：远程放风筝、近身贴身短打、卡位截断退路——距离本身是一种资源

## 2. 部位系统（⑥ 部位面）

### 2.1 身体分解

每个单位（按种族 / 境界有差异）分解为部位：

| 区域 | 部位 | 受伤后果示例 |
|---|---|---|
| 头部 | 眉心（识海）、天灵、面门、咽喉 | 识海毁=神识全失；天灵受创=神志昏聩 |
| 胸腹 | 胸膛、丹田、腰腹 | 丹田毁=道基尽毁；胸创=失血 |
| 手足 | **左臂、右臂、双腿**（v0.3 拆分，独立状态机） | 臂伤=攻击/招架/施法受损（按功法而定）；腿伤=移速身法大减——伤效映射见 §2.5 |

- **攻击可选部位**；**防御可选重点部位**（集中防守：该部位防御速度与强度↑，其余部位↓）+ 敏捷（整体反应速度）——守势宣言详见 §5.1
- 红线：部位是**状态机**，不是「每个部位一条血条」——禁止把部位做成第二套 HP

### 2.2 部位状态机

完好 → 轻伤（功能减弱）→ 重伤（功能丧失）→ 毁（不可逆）

### 2.3 失血

- 未处理的创伤流失**气血**；止血（丹药 / 功法 / 包扎 / 烧灼）可止流失
- **失血按回合结算**（该单位行动时扣一次），不按实时——暂停思考 / 挂机不会流血而死（灼烧等持续状态同理）
- **「一直打对手手臂，只要对方有止血方法，就不会再掉气血」成立**——部位伤害与总血量解耦

### 2.4 要害（境界决定，见《修炼体系》§2.1）

- 击毁要害 = **一击毙命**（或道基尽毁——比死更惨）
- 要害攻击高收益，但**命中门槛更高**（要害部位的速度对抗有惩罚），且防御方会重点保护
- 境界上升 = 要害收敛转移（凡人处处命门 → 化神只剩元神）——高境界怕的不是物理攻击，是神魂攻击

### 2.5 部位伤效（臂腿伤 → 功能修正）

> v0.3 新增。要旨：**受伤不只是掉血**——手臂、腿的伤势直接改写攻防能力；具体伤什么，由**功法的手臂依赖声明**决定（数据驱动，接口纪律）。

**部位结构 v0.3**：「手足」拆分为**左臂 / 右臂 / 双腿**三个部位（各自独立状态机，见 §2.2）；单位声明**主用臂**（惯用手，默认右臂）。三层境界的部位结构同步拆分（《修炼体系》§2.1，代码层 REALM_BODIES）。

**功能域**：攻击力 / 招架值 / 身法（敏捷·闪避）/ 招式熟练度（临时降档）/ 移动步数——五种。

**伤档修正表**（部位状态 → 功能修正，统一由 BodySystem 维护）：

| 部位状态 | 攻击力 | 招架值 | 身法 | 熟练度（临时） | 移动 |
|---|---|---|---|---|---|
| 轻伤 | ×0.7 | ×0.7 | ×0.8 | 按低 1 档称号计算 | 步数 -1（腿） |
| 重伤 | ×0.4 | ×0.4 | ×0.5 | 按低 2 档计算 | 步数减半（腿） |
| 毁 | 依赖此臂的招式禁用 | 禁用 | ×0.3 | — | 无法移动（腿） |

**功法手臂依赖声明（arm_usage）**——每门功法声明双臂各影响哪些功能域：

| arm_usage | 说明 | 主用臂伤 | 非主用臂伤 |
|---|---|---|---|
| 单臂持械 | 剑、刀等单手兵刃 | 攻击 + 招架 | **无影响** |
| 双臂持械 | 枪、重剑、弓等双手兵刃 | 攻击 + 招架 | **攻击 + 招架** |
| 双拳 | 拳脚，双手各半 | 攻击 | 攻击（减半幅度） |
| 副手结印 | 主臂持器、副臂掐诀（玄术） | 攻击 + 招架 | **招式熟练度临时降档** |
| 副手护身 | 副臂主防（招架类功法） | 攻击 | **招架** |
| 身法借力 | 手臂参与平衡借力（身法类） | 攻击 + 招架 | **身法** |

**双手兵刃硬规则**：双臂持械功法中声明「需双臂」的招式，任一手臂**重伤或毁 → 立即禁用**（无法施展需要此手臂的攻击、招架）；轻伤仍可施展，只是攻防修正。

**换手**（主用臂被毁的挽救）：
- 主用臂毁 → 副臂转为主用臂，主臂伤效套用到新主臂
- 换手惩罚：副手生疏——攻击/招架额外 ×0.8（P0 固定值；后续可设计「左剑专精」类功法消除惩罚）
- 双臂皆毁 → 只能施展「心念发动」类招式（不需手臂）或逃跑

**腿部伤效**：轻伤步数 -1、身法 ×0.8；重伤步数减半、身法 ×0.5；毁 → 无法移动、身法 ×0.3——腿伤经「移速（读条）」与「身法（闪避/代受反应）」双通道影响战局。

**境界钩子**：招式声明 `需手臂` 档位（0 心念发动 / 1 单臂 / 2 双臂）——玄术默认需结印（1），**元婴+ 可修「心念发动」变体（0）**：境界越高对肉身的依赖越低，与「高境界怕神魂不怕物理」同主题（P1+ 内容位，数据位 P0 留好）。

**联动**：攻击力修正 → 破防模型（§5）；招架值修正 → 招架对抗（§5.1.3）；身法修正 → 速度对抗（§4）与代受反应（§5.1.4）；熟练度降档 → 招式威力系数（见《功法系统》§2.2）。
**红线**：伤效是**乘区 + 禁用**的机制修正，修正表统一由 BodySystem 维护——禁止各功法自写一套伤效逻辑。

### 2.6 元婴离体与夺舍（高境界的死亡博弈）

- **元婴态**：元婴+ 单位肉身死亡（失血 / 要害毁）时，不立即死亡——元婴遁出，进入**逃亡窗口**（P1+：元婴为高速小单位，N 回合内逃出战场边缘或安全格即存活）
- **反制**：神魂招法 / 寂灭类机制可击杀元婴——肉身死不是结束，**追杀元婴**是高境界战斗的第二阶段
- **夺舍**：元婴态可尝试夺舍低境界单位——神魂对抗判定（魂力 / 规则粗分阶），成功 = 接管其肉身（面板随之），失败 = 元婴反噬受损；**业力重罚**记入功德/业力
- 玩法落点：「杀金丹只需一剑，杀元婴要赢两次」——境界差 = 战斗规则差（P1 后置，数据位已留）

## 3. 无总血条：战斗四池（资源面）

**没有总体血条**，只有四个战斗资源池：

| 池 | 含义 | 归零后果 | 主要来源 / 消耗 |
|---|---|---|---|
| **气血** | 生命之血 | **失血而死** | 创伤持续流失 / 丹药、止血回补 |
| **体力** | 行动体能 | **力竭**（无法行动） | 招式身法消耗 / **<50% 速度渐慢** |
| **玄力** | 术法之力 | 无法施法 | 玄修功法消耗 |
| **魂力** | 神魂之力 | **神魂消散**（高境界真死途径） | 神魂功法 / 神识消耗 |

**三种死法对应三种策略**：磨血（放血耗死）/ 狙击（一击毁要害）/ 灭魂（神魂攻击）。死亡判定与「死亡三途」衔接（见《成长与经济》）。

## 4. 命中结算：速度对抗 + 规则对抗

- **速度维度**：攻击总速度 = 移速 + 敏捷 + 招式速度加成 ± 状态修正；防御总速度 = 移速 + 敏捷 + **招架侧重**加成 ± 状态修正
- 攻 > 防 → **命中**；攻 ≤ 防 → **招架 / 闪避**（防御方消耗体力）
- **规则维度（悟道之力）**：攻击方可**融入规则之力**（消耗玄力），防御方同样可融入反制——**即使动作没有对方快，只要规则领悟碾压对方，依然可以击中**（见 §4.1）
- 判定流程：速度胜 → 命中；速度败但规则差「碾压」（差 ≥ 一阶）→ 仍命中；速度败且规则被反制 / 持平 → 招架
- **高级身法招式**：速度加成大，但消耗更多体力 / 玄力——**用资源买速度**
- 部位影响：腿伤降移速、手伤降攻击速度；debuff（迟滞 / 迟缓 / 剑意溃散）参与修正
- 体力低于 50%：速度逐渐变慢（疲惫惩罚）——控体力 = 控速度 = 控回合
- **本判定只是防御链的第一层（身法闪避）**——闪避之后还有招架 / 代受 / 护体三层，见 §5.1 防御博弈

### 4.1 规则之力（悟道的战斗化）

- 悟道产出**道力**与**规则之力**（见《修炼体系》§2.5），规则领悟分阶：初窥 → 明悟 → 小成 → 大成 → 掌道
- **融入规则**：攻 / 防时主动融入已领悟的规则（消耗玄力）——规则差修正命中，法则给予属性加成；**差 ≥ 一阶 = 碾压**：速度上输了也能靠规则命中
- 法则属性加成（机制级，非数值）：

| 法则 | 攻击融入加成 | 防御融入加成 |
|---|---|---|
| 空间 | 命中修正（隔空锁定） | 闪避修正 |
| 时间 | 读条修正（时序面） | 迟滞对手读条 |
| 火 | 灼烧（状态面） | 焚尽来袭之物 |
| 水 | 渗透连绵（状态面） | 卸力 |
| 金 | **锋锐**——破防加成 | 坚壁 |
| 木 | 缠绕束缚 | 愈伤 |
| 土 | 重压（迟滞） | 厚重防御 |
| 风 | 速度加成 | 卸劲 |
| 雷 | 麻痹（读条迟滞） | 感电反震 |
| 因果 | 命中修正（定业） | 业力偏转 |
| 寂灭 | 部位毁坏倾向 | 寂灭护体 |
| 轮回 | 【待定】 | 【待定】 |

- 红线：规则领悟是**层级**不是面板数值；加成是**机制**（状态 / 破防修正 / 时序），不是「攻击力 +X%」

## 5. 破防模型

- 防御方**总防御** = 装备防御 + 玄气护体 + 肉身强度（**按部位不同**）
- 攻击力 vs 防御，三种结局：

| 对比 | 结果 |
|---|---|
| 攻击力远低于防御 | **无伤**（打不动） |
| 攻击力略低 / 接近防御 | **防御衰减**——磨掉装备耐久、削弱玄气（久攻必破） |
| 攻击力高于防御 | **破防** → 实质伤害（部位受损 / 失血） |

- **要害攻击绕过装备防御**（直取命门，不看装备——但命中更难）→ 高防御重甲角色的天敌
- 防御侧重：把防御资源集中到重点部位，其余部位放空——防御本身也是博弈（v0.3 起护体按部位结算，见 §5.1.5）

### 5.1 防御博弈：守势 · 招架 · 代受（v0.3 核心新增）

> 要旨：**谁也不傻**——击杀对手一定冲要害去，所以守方一定重点保护要害、以武器招架，甚至以手臂或身躯代受，除非战力差距大到根本防不住。防御不是全局旗标，而是**部位级的主动博弈**。

#### 5.1.1 防御四层（由外到内，攻击依次穿透）

| 层 | 手段 | 性质 | 判定 | 代价 |
|---|---|---|---|---|
| ① 身法闪避 | 挪腾躲闪 | 被动常驻 | 速度对抗（§4 现模型） | 无（速度劣势则形同虚设） |
| ② 武器招架 | 兵刃格挡攻击点 | 主动（守势覆盖） | 招架对抗（§5.1.3） | 耗体力、武器耐久；有招架上限 |
| ③ 代受 | 肢体/身躯硬接 | 主动（自动触发） | 反应对抗（§5.1.4） | 代受部位直接受伤（可能毁） |
| ④ 护体玄气 | 玄气/装备兜底 | 被动（按部位） | 破防模型（§5，按部位） | 被磨防则该部位防御衰减 |

- 攻击结算顺序：**闪避 → 招架 → 代受 → 护体**，任何一层成功，其后各层不再发生
- 前三层是「防」，第四层是「挨」——设计意图：**同阶对决很难一招见血**；见血靠打空当、破格挡、磨防或规则碾压

#### 5.1.2 守势宣言（防御方每回合的决策）

- **宣言时机**：防御方在**自己的回合**宣言守势，**保持到主动更改**（不占出招机会，宣言即生效）；**开战时双方先各宣言一次初始守势**（战前对峙，无需消耗）
- **重点保护部位 1~2 个**：护体玄气集中于此（该部位有效防御↑，其余部位↓）；此部位被攻击时自动进入**招架对抗**
- **架势三选**：
  | 架势 | 效果 | 代价 |
  |---|---|---|
  | 招架架势 | 武器格挡，招架判定加成最大 | 本回合机动受限（移动步数 -1） |
  | 闪避架势 | ①层闪避判定加成 | 消耗体力 |
  | 铁壁架势 | ④层护体集中加强 | ①层闪避判定下降——赌「猜中部位」 |
- **无守势**（未宣言或体力不足）：只剩 ①④ 两层——高危状态
- **设计核心**：守势在自己回合设、管到下次行动——守方永远在**猜下一击**，攻方永远在**观察守势再出手**（神识越高看得越清，§8）

#### 5.1.3 招架对抗（②层）

- 触发：攻击部位 ∈ 守方重点保护部位，或守方处于招架架势；**只对物理招式生效**（兵器/拳脚）——玄术/神魂无实体可格，直穿②层（v0.3 实现修订）
- 判定：攻方「力量 + 速度」vs 守方「武器招架值 + 架势加成 + 敏捷」
- 武器招架值由兵刃类型决定：**剑高、枪中、拳/空手最低**（拳修靠身法闪避而非格挡）；招架值有**上限**（境界 + 武器品质）
- 结果：
  - **招架成功**：完全抵消，守方耗少量体力
  - **招架失败 → 破格挡**：攻击穿到下一层；守方武器耐久 -1（耐久归零 = 武器损坏）
  - **碾压破格挡**：攻击力超出守方招架上限 → **武器脱手**（守方武器面板暂时失效，须花一回合拾回【P1】）
- **战力差距阶梯**（「根本防不住」的量化）：
  - 同阶：防御链完整，招架/代受有效
  - 差一阶（境界或规则粗分阶）：招架必破——②层跳过
  - 差两阶以上：护体也形同虚设——破防三态直接判「破防」，且部位伤害加深一档

#### 5.1.4 代受（③层）

- 触发：攻击已越过①②，目标是**要害**，且守方存在可用代受部位
- **可用代受部位**（非致命部位换要害）：手臂 → 代受头部/心脉/眉心神识；肩背/胸腹 → 代受丹田
- 判定：守方反应（敏捷 × 体力修正）vs 攻方速度——**差距大 = 来不及代受**
- 结果：代受成功 = 攻击改落在代受部位上（按破防模型结算，**可能被打到毁**）；代受部位已毁 = 无法再代受
- 设计意图：**代受是消耗战**——守方用手臂换命，但手臂毁 = 攻击力骤降；攻方故意强攻要害逼对方代受，本身就是「远程磨掉对方手臂」的策略
- 元婴+：要害收敛（《修炼体系》§2.1），可代受部位减少——高境界代受更难，对应「境界高不怕物理、怕神魂」

#### 5.1.5 部位化护体（④层，§5 修订）

- 总防御不再全局均摊：**有效防御 = 基础防御 ± 守势集中/放空修正**（按部位）
- 要害攻击绕过装备防御的旧规则保留，但守势集中的护体玄气**可部分抵消**（守势下要害不再是裸的）
- 磨防磨的是**该部位**的防御——守方轮转护体部位，磨防不再无脑

#### 5.1.6 决策空间总结

| 局面 | 攻方选择 | 守方应对 |
|---|---|---|
| 守方重点保护头部 | 打空当（手足/胸腹——易中但非要害） | 轮转保护 / 吃下非致命伤 |
| 攻方强攻要害 | 赌破格挡 / 逼代受（磨掉对方手臂） | 招架 + 代受双保险，烧体力 |
| 相持不下 | 磨防、耗对方体力（招架耗体力 → 累则慢 → 破绽） | 找机会脱离 / 反击【反击机制后置】 |
| 战力碾压 | 无脑强攻——守方一切防护形同虚设 | 逃——认清局势也是策略 |

- **红线**：招架/代受是**机制层**判定，禁止做成「格挡率 X%」式纯概率——判定全部由 力量/速度/规则 对比驱动，确定性内核可回放

## 6. 回合内选择（策略组合空间）

每回合可选：

| 行动 | 决策点 |
|---|---|
| 攻击 | 选部位 × 选招式：速度加成 / 资源消耗 / 部位倾向的权衡 |
| 守势宣言 | 选重点保护部位 1~2 个 + 架势（招架/闪避/铁壁），持续到下次行动（§5.1） |
| 身法 | 走位、闪避，耗体力 / 玄力 |
| 功法机制 | 各道核心循环（剑谱连击 / 布阵 / 炼丹……） |
| 融入规则 | 选已领悟法则注入本次攻防（消耗玄力）——规则对抗修正命中 + 属性加成 |
| 物品 | 止血丹药、符箓——**丹药每回合每种限用一次，不占攻防行动次数**（不同丹药可各自使用） |
| 认输 / 逃跑 | 体面收场，付出代价 |

策略循环 = **读条速度管理 × 部位选择 × 四池资源 × 破防 / 要害博弈**——这正是「道即机制」在战斗层的表达。

## 7. 功法机制在战斗中的表达（对照《功法系统》）

| 功法 | 战斗中玩家实际做什么 |
|---|---|
| 青莲剑歌 | 按剑谱序出招打**部位**（咽喉、手腕优先），管理剑意层数（壹/贰/叁）：破防命中连击升层 → 释放变招（青莲乍开抢速 / 剑意如丝破代受）或叁层赌大招（青莲怒放，出招即倾尽剑意）；被闪避 / 被招架则溃散重来（v0.4 已实装，数值见《功法系统》§3） |
| 太虚阵经 | 选地格布节点、诱敌踏阵、连锁结算 |
| 焚天诀 | 控火势蔓延方向，在烧死敌人前保命 |
| 金石体 | 主动挨打（受击成长），卡淬体进度，选择进化时机 |
| 妖灵契 | 与妖灵共战，管理灵魂力与灵约 |
| 天机演 | 花魂力窥分支，决定要不要回卷一次 |

**验证标准**：两个玩家分别说「我想玩剑修」「我想玩阵修」——若说不出差别，设计失败。

## 8. 信息设计（神识决定信息量）

- 神识低：只看到对手位置、明面上的状态、四池大致
- 神识高：可见对手**部位状态、要害位置、防御侧重、读条进度**——信息差是战力的一部分
- 隐藏与识破是一对机制（藏剑意的功法 vs 勘阵术 vs 神察）

## 9. 一局示例（设计意图演示）

> 剑修（青莲剑歌）对阵 金丹期妖修：
> 1. **开局对峙**：双方宣言守势——你重点保护「咽喉」、剑作招架架势；妖修重点保护「丹田」
> 2. **开局**：妖修移速快，行动条先满，扑向你咽喉（打人族命门）——你的剑堪堪**格挡**（招架成功，它白耗体力）；它第二回合学乖，改攻你放空的手腕——这一下它得手，你手腕轻伤
> 3. **中盘**：你连出剑谱三剑，前两剑打它的手（卸其兵刃，降它攻击速度），第三剑刺它小臂——**创伤持续失血**；它吞丹药止血（失血止，但浪费了一回合）
> 4. **博弈点**：妖修发现你的剑意已至二层，不敢恋战，开始磨你**胸腹部位的护体玄气**（你守势不在胸腹——它在等破防）；你决定抢先：赌一记「高级身法·青莲乍开」，速度加成巨大但耗体力过半（体力惩罚开始逼近）
> 5. **决胜**：这一剑**绕过装备防御直取它丹田**（打金丹！）——丹田正是它的重点保护部位，它来不及变招，**手臂一横代受**——小臂被斩落，丹田保住；你剑势一变，**融入空间规则**（玄力见底也在所不惜）锁定它的眉心神识——它的代受部位已毁、无可代受，速度再快也躲不开这一剑——识海重创，妖修魂力归零，**神魂消散**
> 赢的不是数值，是守势博弈、部位博弈、招架与代受的资源消耗组合

## 10. 设计红线

- [ ] 禁止总体血条回归：战斗胜负必须由失血 / 要害 / 神魂三途径判定
- [ ] 部位是状态机，禁止部位血条化
- [ ] 规则加成禁止数值化：法则加成必须是机制（状态 / 破防修正 / 时序），禁止「攻击力 +X%」
- [ ] 任何功法必须有「独特的输入 / 决策」，禁止纯挂机被动
- [ ] 战斗时长目标：普通斗法 3~6 分钟，渡劫 / 论道可更长
- [ ] 每场战斗至少 2 个有效决策分支，禁止「最优解唯一」
