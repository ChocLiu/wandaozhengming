# 战斗系统

> 状态：初稿 v0.2 · 2026-08-30
> 形态：**回合制策略 · ATB 进度条变体（仙剑三式）**。
> v0.2 核心升级：**部位系统 + 无总血条 + 速度对抗 + 破防模型**——用身体结构与要害博弈替代「血条数值对撞」，这是反数值宣言在战斗层的最直接落地。

---

## 1. 行动方式：ATB 进度条（时序面）

- 每个单位一条**行动条**，读条速度 = **移速 × 体力修正 × 招式修正 × 状态修正**（debuff）
- 条满即行动，行动后清空——**移速快 = 读条快 = 回合多**（速度换行动次数，而不是只换先手）
- 战斗**可暂停 / 慢速**：战术思考时间，暂停中可查看全部信息（神识越高信息越全，见 §8）
- 时序面功法仍然有效：加速 / 迟滞 = 改写对方读条速度；《天机演》窥见的「未来 N 回合」= 未来 N 次行动条结算的分支

### 1.1 战场框架（最小战棋，侠客风云传式）

- **格子战场**：10×10 地格，单位占 1 格（P0 无地形障碍；高低差、朝向后置）
- **回合内移动**：行动窗口内获得移动额度（步数由移速决定，走 1 格耗 1 体力）——**移动与出招顺序自由**（先走后打 / 先打后走）
- **招式射程**：功法声明 range_min/range_max（切比雪夫距离）——兵器近身 1 格、玄术 1~3 格；超出射程出招无效（不消耗出招资源）
- **走位博弈**：远程放风筝、近身贴身短打、卡位截断退路——距离本身是一种资源

## 2. 部位系统（⑥ 部位面）

### 2.1 身体分解

每个单位（按种族 / 境界有差异）分解为部位：

| 区域 | 部位 | 受伤后果示例 |
|---|---|---|
| 头部 | 眉心（识海）、大脑、面门、咽喉 | 识海毁=神识全失；脑受创=行动混乱 |
| 躯干 | 胸、丹田、腰 | 丹田毁=道基尽毁；胸创=失血 |
| 四肢 | 大臂、小臂、手、大腿、小腿、脚 | 手伤=持械不稳；腿伤=移速大减 |

- **攻击可选部位**；**防御可选重点部位**（集中防守：该部位防御速度与强度↑，其余部位↓）+ 敏捷（整体反应速度）
- 红线：部位是**状态机**，不是「每个部位一条血条」——禁止把部位做成第二套 HP

### 2.2 部位状态机

完好 → 轻伤（功能减弱）→ 重伤（功能丧失）→ 毁（不可逆）

### 2.3 失血

- 未处理的创伤持续流失**气血**；止血（丹药 / 功法 / 包扎 / 烧灼）可止流失
- **「一直打对手手臂，只要对方有止血方法，就不会再掉气血」成立**——部位伤害与总血量解耦

### 2.4 要害（境界决定，见《修炼体系》§2.1）

- 击毁要害 = **一击毙命**（或道基尽毁——比死更惨）
- 要害攻击高收益，但**命中门槛更高**（要害部位的速度对抗有惩罚），且防御方会重点保护
- 境界上升 = 要害收敛转移（凡人处处命门 → 化神只剩元神）——高境界怕的不是物理攻击，是神魂攻击

## 3. 无总血条：战斗四池（资源面）

**没有总体血条**，只有四个战斗资源池：

| 池 | 含义 | 归零后果 | 主要来源 / 消耗 |
|---|---|---|---|
| **气血** | 生命之血 | **失血而死** | 创伤持续流失 / 丹药、止血回补 |
| **体力** | 行动体能 | **力竭**（无法行动） | 招式身法消耗 / **<50% 速度渐慢** |
| **玄力** | 术法之力 | 无法施法 | 玄修功法消耗 |
| **魂力** | 神魂之力 | **神魂消散**（高境界真死途径） | 神魂功法 / 神识消耗 |

**三种死法对应三种策略**：磨血（放血耗死）/ 狙击（一击毁要害）/ 灭魂（神魂攻击）。死亡判定与「死亡三途」衔接（见《成长与经济》）。

## 4. 命中结算：速度对抗 + 规则对抗

- **速度维度**：攻击总速度 = 移速 + 敏捷 + 招式速度加成 ± 状态修正；防御总速度 = 移速 + 敏捷 + **招架侧重**加成 ± 状态修正
- 攻 > 防 → **命中**；攻 ≤ 防 → **招架 / 闪避**（防御方消耗体力）
- **规则维度（悟道之力）**：攻击方可**融入规则之力**（消耗玄力），防御方同样可融入反制——**即使动作没有对方快，只要规则领悟碾压对方，依然可以击中**（见 §4.1）
- 判定流程：速度胜 → 命中；速度败但规则差「碾压」（差 ≥ 一阶）→ 仍命中；速度败且规则被反制 / 持平 → 招架
- **高级身法招式**：速度加成大，但消耗更多体力 / 玄力——**用资源买速度**
- 部位影响：腿伤降移速、手伤降攻击速度；debuff（迟滞 / 迟缓 / 剑意溃散）参与修正
- 体力低于 50%：速度逐渐变慢（疲惫惩罚）——控体力 = 控速度 = 控回合

### 4.1 规则之力（悟道的战斗化）

- 悟道产出**道力**与**规则之力**（见《修炼体系》§2.4），规则领悟分阶：初窥 → 明悟 → 小成 → 大成 → 掌道
- **融入规则**：攻 / 防时主动融入已领悟的规则（消耗玄力）——规则差修正命中，法则给予属性加成；**差 ≥ 一阶 = 碾压**：速度上输了也能靠规则命中
- 法则属性加成（机制级，非数值）：

| 法则 | 攻击融入加成 | 防御融入加成 |
|---|---|---|
| 空间 | 命中修正（隔空锁定） | 闪避修正 |
| 时间 | 读条修正（时序面） | 迟滞对手读条 |
| 火 | 灼烧（状态面） | 焚尽来袭之物 |
| 水 | 渗透连绵（状态面） | 卸力 |
| 金 | **锋锐**——破防加成 | 坚壁 |
| 木 | 缠绕束缚 | 愈伤 |
| 土 | 重压（迟滞） | 厚重防御 |
| 风 | 速度加成 | 卸劲 |
| 雷 | 麻痹（读条迟滞） | 感电反震 |
| 因果 | 命中修正（定业） | 业力偏转 |
| 寂灭 | 部位毁坏倾向 | 寂灭护体 |
| 轮回 | 【待定】 | 【待定】 |

- 红线：规则领悟是**层级**不是面板数值；加成是**机制**（状态 / 破防修正 / 时序），不是「攻击力 +X%」

## 5. 破防模型

- 防御方**总防御** = 装备防御 + 玄气护体 + 肉身强度（**按部位不同**）
- 攻击力 vs 防御，三种结局：

| 对比 | 结果 |
|---|---|
| 攻击力远低于防御 | **无伤**（打不动） |
| 攻击力略低 / 接近防御 | **防御衰减**——磨掉装备耐久、削弱玄气（久攻必破） |
| 攻击力高于防御 | **破防** → 实质伤害（部位受损 / 失血） |

- **要害攻击绕过装备防御**（直取命门，不看装备——但命中更难）→ 高防御重甲角色的天敌
- 防御侧重：把防御资源集中到重点部位，其余部位放空——防御本身也是博弈

## 6. 回合内选择（策略组合空间）

每回合可选：

| 行动 | 决策点 |
|---|---|
| 攻击 | 选部位 × 选招式：速度加成 / 资源消耗 / 部位倾向的权衡 |
| 防御 | 选重点部位 + 架势（招架侧重），消耗体力 |
| 身法 | 走位、闪避，耗体力 / 玄力 |
| 功法机制 | 各道核心循环（剑谱连击 / 布阵 / 炼丹……） |
| 融入规则 | 选已领悟法则注入本次攻防（消耗玄力）——规则对抗修正命中 + 属性加成 |
| 物品 | 止血丹药、符箓 |
| 认输 / 逃跑 | 体面收场，付出代价 |

策略循环 = **读条速度管理 × 部位选择 × 四池资源 × 破防 / 要害博弈**——这正是「道即机制」在战斗层的表达。

## 7. 功法机制在战斗中的表达（对照《功法系统》）

| 功法 | 战斗中玩家实际做什么 |
|---|---|
| 青莲剑歌 | 按剑谱出招打**部位**（咽喉、手腕优先），管理剑意层数，预判被打断 |
| 太虚阵经 | 选地格布节点、诱敌踏阵、连锁结算 |
| 焚天诀 | 控火势蔓延方向，在烧死敌人前保命 |
| 金石体 | 主动挨打（受击成长），卡淬体进度，选择进化时机 |
| 妖灵契 | 与妖灵共战，管理灵魂力与灵约 |
| 天机演 | 花魂力窥分支，决定要不要回卷一次 |

**验证标准**：两个玩家分别说「我想玩剑修」「我想玩阵修」——若说不出差别，设计失败。

## 8. 信息设计（神识决定信息量）

- 神识低：只看到对手位置、明面上的状态、四池大致
- 神识高：可见对手**部位状态、要害位置、防御侧重、读条进度**——信息差是战力的一部分
- 隐藏与识破是一对机制（藏剑意的功法 vs 勘阵术 vs 神察）

## 9. 一局示例（设计意图演示）

> 剑修（青莲剑歌）对阵 金丹期妖修：
> 1. **开局**：妖修移速快，行动条先满，扑向你咽喉（打人族命门）；你判断其路径，招架侧重放在咽喉，挡下这一击（速度对抗：招架 > 攻击）
> 2. **中盘**：你连出剑谱三剑，前两剑打它的手（卸其兵刃，降它攻击速度），第三剑刺它小臂——**创伤持续失血**；它吞丹药止血（失血止，但浪费了一回合）
> 3. **博弈点**：妖修发现你的剑意已至二层，不敢恋战，开始磨你的**装备防御**（它攻击力略低于你的护体玄气——它在等破防）；你决定抢先：赌一记「高级身法·青莲乍开」，速度加成巨大但耗体力过半（体力惩罚开始逼近）
> 4. **决胜**：这一剑**绕过装备防御直取它丹田**（打金丹！）——它被迫集中防御丹田，头部放空；你剑势一变，**融入空间规则**（玄力见底也在所不惜）锁定它的眉心神识——它的速度比你快也躲不开这一剑——识海重创，妖修魂力归零，**神魂消散**
> 赢的不是数值，是速度博弈、部位博弈与资源博弈的组合

## 10. 设计红线

- [ ] 禁止总体血条回归：战斗胜负必须由失血 / 要害 / 神魂三途径判定
- [ ] 部位是状态机，禁止部位血条化
- [ ] 规则加成禁止数值化：法则加成必须是机制（状态 / 破防修正 / 时序），禁止「攻击力 +X%」
- [ ] 任何功法必须有「独特的输入 / 决策」，禁止纯挂机被动
- [ ] 战斗时长目标：普通斗法 3~6 分钟，渡劫 / 论道可更长
- [ ] 每场战斗至少 2 个有效决策分支，禁止「最优解唯一」
