# 局内循环与秘境结构

> 状态：初稿 v0.1 · 2026-09-05
> 本文档填补「一次游玩会话长什么样」的宏观结构空白：**沙盒世界管长线，秘境管局内循环**。动因是外部「参考杀戮尖塔换壳」提议引发的结构审计——汲取其**节奏骨架**与**奖励哲学**，拒绝其**掉落 / 数值 / 死亡新局**（见 §5）。秘境落地时点留待 P1 排期（见 §3）。

---

## 1. 定位与分工：沙盒 + 秘境

本作是**开放沙盒修仙 RPG**（《游戏定位与设计支柱》§2），不是 roguelike run 游戏。宏观结构分两层：

| 层 | 职责 | 时长尺度 | 对应假设 |
|---|---|---|---|
| **沙盒层**（主层） | 门派 / 势力 / NPC 修炼 / 自创功法闭环 / 死亡三途的世界内延续 / 终极目标（席位之争） | 数小时 ~ 数百小时，世界状态持久 | H3（悟道成长动力）、支柱三（世界是活的） |
| **秘境层**（局内循环） | 一次游玩的节奏单元：有限层数、节点地图、战间选择、可重复游玩 | 约 30~60 分钟一场（初值，待手感调参） | H3 的「持续动力」来源之一、H4 的连战场景 |

- 沙盒层是**本体**；秘境层是嵌入沙盒的**结构件**——秘境有世界内的位置、开合时机与进入代价（见 §2.1），不是「从主菜单点进一局」的独立模式。
- 两者的接口：秘境产出（感悟 / 残篇 / 机缘 / 灵石）回流沙盒层，驱动功法获取与突破（《成长与经济》§1 循环）；沙盒层状态（境界 / 功法 / 气运 / 人情）决定秘境内的实力与际遇。

## 2. 秘境 = 局内循环

### 2.1 秘境的世界内身份（为什么存在，为什么能进）

秘境不是凭空副本，是**世界地理的一部分**：

- **形态**：上古洞府、大能遗蜕之地、灵潮冲刷出的裂缝、宗门禁地试炼——都有来历与守护者。
- **开合**：随**灵潮涨落**（《成长与经济》§6）周期性开启关闭——涨潮开启、退潮关闭，秘境的时间窗口是世界事件，不是无限刷。
- **进入代价**：需要**名额**——「进秘境名额」已写入人情资源的用途（《成长与经济》§2），由门派分配 / 人情兑换 / 机缘所得；境界不足不可入（高境界洞府有禁制）。
- **反刷**：同一秘境反复进出，机缘与感悟收益按「经历新鲜度」指数衰减（《成长与经济》§1 反刷设计的世界层版本）——秘境是**经历**，不是矿点。

### 2.2 节点地图骨架（汲取杀戮尖塔之节奏）

秘境内部 = 多层结构（如「九重洞府」，层数因秘境而异）。每层一张**节点图**：分层、分叉、节点类型**可见**（踏入前已知前方是斗法还是奇遇——路线选择是策略）。节点类型映射：

| 节点 | 内容 | 节奏作用 | 对应杀戮尖塔原型 |
|---|---|---|---|
| **斗法** | 遭遇战：妖兽 / 魔修 / 傀儡 / 心魔——每个敌人是**一道机制考题**（如「此妖专断兵刃」= 考招架反制） | 常规战斗，风险基础 | 普通战斗 |
| **守关妖兽** | 精英战：高风险高回报，**守护着遗藏**（打赢才能取） | 风险/回报尖峰 | 精英 |
| **奇遇** | 机缘事件：遇前辈讲道、发现残篇、救人结因果、幻境问道——结果受**气运**修正 | 变数与叙事 | 事件 |
| **坊市** | 秘境墟市 / 游方散修摆摊：**灵石交易**（灵石是消耗品通货，花在这里就烧不到别处） | 消费抉择 | 商店 |
| **打坐** | 疗伤 + 参悟：把本场获得的感悟**固化为可用的成长**（推演 / 突破素材），或纯疗伤保命 | 休整与成长节点 | 篝火 |
| **遗藏** | 前辈洞府遗留：**二选一继承**（礼敬前人，拿一件留一件——拿/舍张力的集中点） | 构筑奖励 | 宝箱 |
| **守层大妖** | 每层末尾 Boss：机制复合、卡死则秘境止步 | 层次验证 | Boss |

- **路线可见性**：节点类型踏入前已知、下一层入口可见——「我该不该贪那个守关妖兽的遗藏」是每层的核心决策。
- **守层大妖必打、守关妖兽可绕**：绕过的遗藏永久失去（本场），不可回头——取舍不可两全。

### 2.3 节奏与时长

- 单场斗法 3~6 分钟（《战斗系统》§9 红线既有约束）× 每层 5~7 节点 × 3 层（初值，待手感调参）→ 一场秘境约 30~60 分钟。
- 打坐节点是**节奏阀**：伤重则被迫放慢贪心——疗伤与成长的资源分配本身就是决策。
- 秘境途中**不可存档点外退出**？【待定】——倾向：可随时退（沙盒本体随时可回），但退出即本场止步，机遇不再。

### 2.4 奖励因果链（红线检查单的核心证明）

所有奖励必须有**世界内来源**——禁止「战斗结算凭空掉落」：

| 奖励 | 世界内来源 | 对应红线 |
|---|---|---|
| **感悟** | 斗法 / 奇遇 / 讲道——「值得一悟」的经历（非每场必给，质量 > 数量） | 成长闭环（《成长与经济》§7） |
| **残篇** | 遗藏二选一、奇遇发现、坊市购得——是**世界上存在过的功法**的残页，有出处 | 功法获取有因果（反套路 #1） |
| **机缘 / 气运** | 奇遇、救人、了结因果——功德业力账本联动（《成长与经济》§2） | 世界逻辑自洽 |
| **灵石** | 坊市交易、斗法彩头、遗藏遗物 | 灵石是消耗品，通货流动 |
| **法宝 / 异宝** | 守关妖兽**守护**之物、洞府主人**留待有缘**——器灵双向选择（《成长与经济》§5） | 反词条、有来历 |

- **构筑张力（拿/舍）**：残篇同一时间只能参悟一份（贪多嚼不烂）；遗藏二选一；坊市买/不买；打坐参悟 vs 继续深入——**奖励永远带着放弃**，这是从杀戮尖塔「拿卡 / 删卡」抽象出的结构，而非其掉落形式。

### 2.5 随机性定位：随机在结构，确定在判定

- **结构层随机**：节点布局、奇遇内容、敌人编组——生成可注入 seed（秘境有「气机」），且奇遇触发受**气运**修正（气运是玩家行为攒出来的，不是抽出来的）。
- **判定层确定**：一切战斗判定对比驱动、无纯概率（《战斗系统》§10 红线）——斗法仍是那个可回放的斗法。
- 一句话：**机遇随机，胜负确定**。与「确定性内核 + 可回放」技术红线（《Godot技术选型与架构》§2.3）完全兼容。

### 2.6 死亡三途 × 秘境

- 秘境中战死**不走「run 失败读档」**，按**死亡三途**在世界内延续（《成长与经济》§4）：兵解 / 执念 / 轮回——死去的角色变成新的玩法，秘境之战可能正是一段执念任务链的起点。
- 秘境失败（被打出 / 退出）= 本场止步，世界线继续：秘境仍在（灵潮窗口内可再入），但机遇不再、奇遇不重来。
- 与杀戮尖塔「死亡 = 开新局」的本质区别：**局会结束，世界不结束**。

## 3. 与路线图衔接（待 P1 排期时定）

秘境首次落地两个方案，各述取舍，**本文档不代拍板**：

| 方案 | 时机 | 取舍 |
|---|---|---|
| **A. P1 尾落地** | 作为**功法获取循环的载体**（拜师/机缘/感悟/抢夺四大途径中「机缘」的实体化：小地图上 1 个入门级秘境） | 优：H3 验证（悟道成长动力）多一个强力场景；功法获取不依赖 NPC 排期。劣：P1 范围已重（小地图+门派+NPC+推演），秘境是增量风险 |
| **B. P2 落地** | 作为**独立层**（灵潮事件 + 第二地图区域 + 装备系统的组合场：秘境开合随灵潮，法宝/异宝入 P2 装备线） | 优：P1 范围不膨胀；与灵潮/装备系统同批，机制协同好。劣：H3 验证期缺一块「战间结构」的试金石，P1 切片可能显得只有沙盒闲逛 |
| **C.【备选】P1 末期试水** | 连战原型（无地图）：battle 内核加「遭遇 + 战间成长选择」最小层，验证 §2 的节奏手感 | 优：验证成本最低、可回退。劣：没有地图的秘境不是秘境——只能验证「连战节奏」，节点结构验证不了 |

倾向声明（供排期参考，非决议）：**C 试水 → B 完整落地**——用最小连战层先验证节奏手感，完整秘境随灵潮/装备系统在 P2 落地；若 P1 期间 H3 验证乏力，再启用 A。

## 4. 红线检查单（按《游戏定位与设计支柱》§5 逐条过审）

- **是否引入了新机制？** 是——但它是「结构层」机制（节点图 / 开合窗口 / 名额），服务的仍是既有假设 H3/H4，不新增验证目标。
- **是否可与其他机制组合？** 是——节点类型是六大交互面在**世界层**的组合接口：气运修正奇遇、寿元 / 境界限制准入、人情换名额、功德业力改际遇、功法影响打坐参悟效率——秘境与现有系统互留接口，不留孤岛。
- **是否只是数值变化？** 否——奖励全是机制载体（功法残篇 / 规则修改型异宝 / 感悟），无「+10%」式产出。
- **是否破坏世界逻辑（凭空掉落）？** 否——§2.4 逐条证明每个奖励有世界内来源；秘境本身有地理位置、开合因果与进入代价。
- **补充：是否破坏确定性内核？** 否——§2.5 随机只作用于结构层（可 seed），判定层仍可回放。

## 5. 汲取声明：三借三不借

外部提议「参考杀戮尖塔换壳」的结构审计结论：

| | 内容 | 理由 |
|---|---|---|
| **借 ①** | 节点地图的**节奏骨架**（战斗/事件/商店/篝火/宝箱/Boss 的交替与路线选择） | 它是「一局 30~60 分钟」最成熟的切分法，本作元循环空白正缺此物 |
| **借 ②** | **遗物哲学**：奖励改规则不改数值 | 与「道即机制」完全同构——是本作红线的外部印证，落 P2 法宝 / 异宝设计（《成长与经济》§5） |
| **借 ③** | **构筑张力**：拿什么 = 舍什么 | 抽象为「奖励永远带着放弃」（§2.4），拒绝其「战后三选一掉卡」形式 |
| **不借 ①** | 战后三选一掉卡 | 凭空掉落——功法获取必须有世界内因果（反套路 #1） |
| **不借 ②** | 死亡开新局 | 死亡三途 = 同世界延续（反套路 #6），「局会结束，世界不结束」 |
| **不借 ③** | 数值卡牌与随机发牌 | 道即机制（支柱一）+ 确定性内核——判定永远对比驱动 |

**无需借而本作已有的东西**：意图可见——神识信息量（《战斗系统》§8）、守势宣言制（§5.1.2）、剑意层数显式可见（《功法系统》§3）已是比杀戮尖塔「敌人头顶意图图标」更深的版本。杀戮尖塔对本作的最终角色是**结构参考答案 + 红线外部印证**，不是换壳蓝本。
