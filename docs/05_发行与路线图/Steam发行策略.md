# Steam 发行策略

> 状态：初稿 v0.1 · 2026-08-30
> 回答立项问题：「独立游戏是不是先考虑 Steam 上架比较好？」——**是的，PC + Steam 是独立游戏最现实的第一站。**

---

## 1. 为什么是 Steam（立项结论）

| 维度 | 说明 |
|---|---|
| **成本** | Steam Direct 上架费 **$100**（一次性，游戏收入达标后可退还）——独立游戏能承受的最低门槛 |
| **版号** | **不需要版号**（版号只约束国内发行渠道；若将来上 WeGame/国行商店才需要） |
| **市场** | PC 最大的独立游戏分发平台，全球市场；修仙（Cultivation）题材在海外独立游戏圈已是被验证的热门标签（鬼谷八荒、觅长生海外销量可观） |
| **模式** | 抢先体验（Early Access）天生适合本作——系统驱动型游戏需要长线迭代，EA 期间玩家反馈正是「试水」的延续 |
| **基础设施** | 愿望单、成就、云存档、工坊（mod）全套现成 |

**结论**：Steam 是默认路线，不是可选项。现在就可以做的事：注册 Steamworks 账号（需要 $100），越早越好。

## 2. 时间线（与路线图联动）

| 阶段 | 发行动作 |
|---|---|
| **现在（P0 期）** | 注册 Steamworks 开发者账号；想好商店页品牌名（中英文） |
| **P1 垂直切片** | **商店页上线**（卖相足够时——有 60 秒宣传片 + 8~10 张截图 + 描述文本）；开始攒**愿望单** |
| **P1 末期 ~ P2** | 发布 **Demo**（垂直切片直接转 Demo）；报名 **Steam Next Fest 新品节**（Demo 免费曝光的最强渠道） |
| **P3 起** | **EA 发售**（定价参考同类独立修仙游戏：$15~20【待定】）；持续更新驱动长尾销量 |

## 3. 商店页要点

- **标签**：修仙 / Cultivation、回合制、沙盒、RPG、策略——Cultivation 标签务必打上（海外受众搜索入口）
- **语言**：简中 + 英文双语商店页（本作文案量后期很大，翻译成本要在 P2 预算里留出【待定】）
- **卖点排序**（宣传物料统一口径）：
  1. 功法即机制——每门功法是完全不同的玩法
  2. 自由组合与自创功法——做出你自己的道
  3. 多种族混血、不同修炼模式
  4. 无抽卡无经验条的修仙沙盒
- **商店页素材清单**：宣传片（战斗机制展示优先于剧情）、截图（战斗界面/功法界面/自创界面）、动态头像/横幅

## 4. 重要风险与合规

- **AI 生成内容披露**：Steam 要求商店页披露游戏是否含 AI 生成内容。**本工作区有 ComfyUI**——若游戏最终使用 AI 生成的图/音/文本素材，必须在商店页如实披露，并确保工作流合规（无侵权训练数据）。建议：AI 只用于概念探索与临时占位，正式素材尽量人工/可商用素材库，或至少完整留档提示词与工作流（目录约定见 art/README.md）
- **商标与名称**：《万道争鸣》上架前需查重（Steam 商店搜索 + 商标查询），正式定名前完成
- **愿望单是命脉**：商店页早开一天，愿望单多攒一天；EA 发售时的愿望单数量与首周销量强相关

## 5. 国内 vs 海外

- **海外优先**：Cultivation 题材海外有稳定受众，且无版号问题——Steam 全球同步上
- **国内**：Steam 国区本身就是国内市场的重要渠道（无需版号）；若要上 WeGame 等国内平台，需要版号 + 审核，等游戏有成绩再评估
