# 世界观设定

> 状态：初稿 v0.1 · 2026-08-30
> 原则：**世界观的每一条设定都要有玩法落点**。凡是没有玩法落点的设定，暂缓细化（避免世界观膨胀拖累开发）。

---

## 1. 宇宙观：大道五十，天衍四十九

天地初开，**大道**化生五十条道（法则），但天道只显化了四十九条——**「遁去的一」**始终空缺。万族修炼，本质都是在四十九条道中寻找自己的位置。

**玩法落点**：这空缺的第五十条道，就是留给**玩家的**。玩家自创功法、立道证道，最终目标是让自己的道补全天道——「万道争鸣」争的正是这个名额。这是主线长线目标，也让自创功法系统有了世界观级的动机。

## 2. 修炼介质：灵气不是唯一的路

不同种族/道路的修炼介质完全不同——这是「不同修炼模式」的世界观基础：

| 介质 | 使用者 | 特点 |
|---|---|---|
| 灵气 | 人族主流、灵族 | 最常见，但灵潮有涨落 |
| 煞气/剑气等 | 人族各道 | 各道有各自的「道气」（剑意、丹香、阵势） |
| 妖元 | 妖族 | 源于血脉与日月精华 |
| 怨气/执念 | 鬼族 | 源于生前执念与死后香火 |
| 魔气 | 魔族 | 源于欲望与杀戮，强但噬主 |
| 器韵 | 器族 | 源于被使用与祭炼 |

**玩法落点**：不同介质 = 不同资源循环的**初始设定**（资源面）。混血/跨界修炼者需要处理介质冲突（详见种族与血脉文档）。

## 3. 历史纪元（四纪）

| 纪元 | 事件 | 留下的玩法遗产 |
|---|---|---|
| **太古·道争** | 万族由大道衍生，为争夺「道位」爆发第一次道争，天道立四十九条道 | 上古秘境、大道遗迹（探索内容） |
| **上古·绝地天通** | 神裔与古族隐退，各族在隔绝中独立演化出各自的修炼路 | 种族差异的起源解释 |
| **近古·万道争鸣** | 人族崛起，百家道统并立，讲道、论道、道统之争成为常态 | **游戏当下**：门派林立、道统传承网络（核心玩法背景） |
| **当代·灵潮** | 灵气周期性涨落，涨潮时机缘井喷，退潮时资源枯竭、势力洗牌 | **世界动态事件**：灵潮驱动世界周期性变化（详见成长与经济文档） |

## 4. 种族一览（详见《种族与血脉》文档）

| 种族 | 一句话 | 修炼模式 |
|---|---|---|
| 人族 | 万法皆通，悟性见长，寿元最短 | 兼容一切功法，但每门功法都有寿元成本 |
| 妖族 | 血脉为本，化形为槛 | 血脉觉醒树 + 本体形态 |
| 鬼族 | 执念成形，无实体 | 执念驱动，香火/怨气为食 |
| 魔族 | 以杀证道，魔气噬主 | 高风险高回报的杀戮循环 |
| 灵族 | 天生地养，纯粹而缓慢 | 天地交感，但被「炼化」是宿命威胁 |
| 器族 | 器灵觉醒，与主共生 | 被使用中成长，受制于器主 |

## 5. 势力格局（骨架版）

- **人族**：剑宗（攻伐第一）、丹盟（垄断续命资源）、阵阁（阵法贸易）、魔道散修（自由但危险）——四大方向对应初始功法接触面
- **妖族**：万妖山（妖族正统）、散妖（化形劫失败者的流亡地）
- **鬼族**：酆都阴司（秩序鬼）、野鬼（怨气失控）
- **灵族**：灵墟（灵族避难所，防备被炼化）
- **器族**：器冢（无主之器的归宿）
- **中立**：坊市（灵石经济中心）、散修联盟

**玩法落点**：势力 = 功法获取渠道 + 因果归属。杀一个剑宗弟子，剑宗会寻仇；拜入丹盟，能接触丹方传承。

## 6. 核心悬念（主线钩子）

1. **遁去的一**为何空缺？——主线线索，贯穿自创功法系统
2. **灵潮**为何紊乱？——世界动态的主事件，各大势力的明争暗斗皆源于此
3. **混血者**的禁忌身份——玩家若选择混血出身，自带一条被两族排斥的隐线
