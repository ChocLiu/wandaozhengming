# 世界观设定

> 状态：初稿 v0.2 · 2026-08-30
> 原则：**世界观的每一条设定都要有玩法落点**；**每个时代都是完整的世界快照**（为未来的「时间长河」穿越玩法储备）。

## 1. 宇宙观：大道层级（关系总图）

> 「道生一，一生二，二生三，三生万物。」——《道德经》
> 本节回答一个核心问题：**大道、天道、四十九条大道、六道、道之树，彼此是什么关系？**

天地万物皆由**大道**衍生。大道之下分两层：**天道（规则层）**与**六道（生灵层）**：

```
大道（本源，无上唯一——其「未分」之态即混沌）
│
├── 天道（大道的显化——天地运行的规则层，天衍四十九）
│   ├── 四十九条大道（因果 / 时间 / 生死 / 寂灭……49 个道祖席位）
│   └── 遁去的一（第五十席 · 空缺至今——自证之位）
│
└── 六道（生灵层——大道为众生立下的六条祖道之路，太古道争定序）
    ├── 天道（神族之路：化身规则——与规则层天道互为表里）
    ├── 人道（人族之路）　修罗道（魔族之路）
    ├── 畜生道 / 妖道（妖族之路）
    ├── 饿鬼道（鬼族 · 游魂之路）　地狱道（鬼族 · 阴司之路）
    └── （第七祖道之位 · 失落——巫道，本应与六道并列）
        └── 道系 → 万道 → 功法 → 术法（此即「道之树」）
```

### 1.1 逐项关系表

| 概念 | 是什么 | 关键关系 |
|---|---|---|
| **大道** | 万法之源，唯一 | 混沌是其未分之态；「终成大道」= 与它合一 |
| **天道** | 大道的显化，天地规则的总和 | 「天衍四十九」= 天道显化出 49 条规则大道 |
| **四十九条大道** | 规则层的 49 个席位（因果、时间、生死……） | 证天道 = 合入其中一席；每席一位道祖 |
| **遁去的一** | 规则层的第五十席，空缺至今 | 自证 = 开此席——「补全天道」的正解 |
| **六道** | 生灵层的六条祖道之路 | 生灵在 49 条规则之下走出的六类修行路径 |
| **道之树** | 六道及以下的完整分类树：六道→道系→万道→功法→术法 | 49 大道是树顶之上的「天」，不是树的节点 |
| **第七祖道（失落）** | 生灵层本应有七道——巫道失落于太古道争 | 与「第五十席」是**两处不同的空缺**（§1.3） |

### 1.2 「天道」为什么出现两次（同名之谜）

- 规则层的**天道** = 天地运行的规则总和（四十九条大道）
- 六道中的**天道** = 神族之路——修神格、争香火神位，本质是**把自己修成规则的化身**
- 两者同名不是巧合：神族走的天道之路，正是通往规则层天道的**捷径**。所以「证天道」（合入 49 席）既是天道之路的终点，也向一切种族开放——任何生灵合入一席都叫证天道；不愿合入旧席者，便去自证新席
- 规则大道不与六道一一对应——它们是「理」，六道是「路」；但每条路天然更近某些理（神族之路近规则本身，魔族之路近杀戮/吞噬，妖族之路近血脉/万灵……）

### 1.3 两处空缺（设计对称）

- **天缺一席**：四十九条大道之外，第五十席「遁去的一」空缺——自证之位（规则层）
- **地缺一道**：六道之外，第七祖道之位失落——巫道之位（生灵层）
- 巫族「最接近遁去的一」，因为巫道与「一」**同为道外**——补全天道有两条路：**找回第七道，或开第五十席**（主线双线）

- **太古道争**：万族争的既是六道祖道之位，也是四十九大道席位——「万道争鸣」的终极含义，就是这四十九席
- 修炼的本质：**从术法逐级向上，功法合道，直至证道**。玩家修的是万道中的某一道（剑道、丹道、妖灵道……）；自创功法 = 在万道之中开辟属于自己的新位置；终极目标是席位之争——证天道或自证（见 §3）

**玩法落点**：境界体系的世界坐标（《修炼体系》）、自创功法的层级归属（《功法系统》）。

## 2. 六道与种族归属

六道为六大祖道，每个种族生而归属其下：

| 六道 | 归属 | 特点 |
|---|---|---|
| **天道** | 神族 | 神格、香火神位 |
| **人道** | 人族（器族附焉） | 百家道统、万法皆通 |
| **修罗道** | 魔族 | 修罗、罗刹、天魔、血魔、心魔、夜叉 |
| **畜生道（妖道）** | 妖族 | 龙族为尊，万物可化神兽 |
| **饿鬼道** | 鬼族·游魂 | 执念、香火 |
| **地狱道** | 鬼族·阴司 | 秩序、轮回、尸傀 |

**道外之族**（不在六道之内——身份特殊，天然与主线相连）：
- **巫族**：巫道本应与六道并列——生灵层本应有七道，巫道在太古道争中失落第七祖道之位 → 巫族由此衰落。**巫道与「遁去的一」同为道外，故巫族最接近它**（§1.3、§9）
- **灵族**：自然孕育之灵，天地交感，不入六道
- **混沌遗族**【隐藏】：混沌之气所化，详情待玩家发掘

> 注：「畜生道」为天道定名，妖族自称**妖道/万灵道**——称谓之争本身就是世界观的恩怨（妖族对天道的旧恨）。
> 注2：「天道」之名有两层含义——规则层的天道（四十九条大道）与六道中的天道（神族之路），同名之谜见 §1.2。

### 2.1 道之树（万道谱系·初稿）

层级定义：**六道（祖道）→ 道系（子节点）→ 万道（叶节点）→ 功法（叶上之法）→ 术法（末梢）**（树之上另有四十九条规则大道与遁去的一，见 §1）。初步谱系如下，标【扩展】的不进 P0~P2：

```
大道
├─ 天道（神族）
│   ├─ 神格系：战神道 · 月神道 · 星君道 · 雷神道……
│   └─ 香火系：城隍道 · 山神道 · 河神道 · 灶神道……
├─ 人道（人族，器族附）
│   ├─ 兵道系：剑道 · 刀道 · 枪道 · 拳道 · 体道
│   ├─ 术道系：丹道 · 器道 · 阵道 · 符道 · 御兽道 · 五行道（火行/水行/金行/土行/木行）
│   ├─ 玄道系：玄门道 · 心道 · 梦道【扩展】
│   ├─ 冥术系：鬼修道 · 魂道 · 尸傀道
│   ├─ 杀道系：血道 · 毒蛊道 · 魔功道（借魔气）
│   └─ 灵契系：妖灵道 · 御灵道【扩展】
├─ 修罗道（魔族）
│   ├─ 战道系：修罗战道 · 狂战道
│   ├─ 魔气系：天魔道 · 夜叉炼体道
│   ├─ 幻道系：罗刹魅道 · 心魔道
│   └─ 嗜血系：血魔道 · 噬魂道
├─ 畜生道/妖道（妖族）
│   ├─ 龙道系：金龙道 · 青龙道 · 烛龙道 · 应龙道 · 蛟龙道……
│   ├─ 兽道系：走兽道 · 飞禽道 · 水族道 · 鳞甲道
│   ├─ 返祖系：凤凰道 · 九尾道 · 鲲鹏道 · 麒麟道……（神兽进化终点）
│   └─ 化形系：化形道 · 妖丹道
├─ 饿鬼道（鬼族·游魂）
│   ├─ 执念系：执念道 · 香火道 · 厉鬼道
│   └─ 往生系：超度道 · 往生道
├─ 地狱道（鬼族·阴司）
│   ├─ 阴司系：阴差道 · 判官道 · 阎罗道
│   ├─ 尸道系：尸王道 · 傀道
│   └─ 刑道系：地狱刑道
└─ 【道外】
    ├─ 巫道（巫族）：十二祖巫血脉道（祝融道 · 共工道 · 后土道 · 蓐收道 · 句芒道 · 玄冥道 · 强良道 · 天吴道 · 翕兹道 · 帝江道 · 烛九阴道 · 奢比尸道）
    ├─ 自然道（灵族）：金行 · 木行 · 水行 · 火行 · 土行 · 风雷冰异行
    └─ 混沌道【隐藏】
```

**树的玩法意义**：
- **功法获取 = 沿树攀爬**（拜师/宗门 = 进入某条枝干的传承链）
- **自创功法 = 树上开新叶**（L3 立道成功后，万道谱系多出一个新节点——这就是「世界功法库」的结构）
- **血脉 = 树的访问权限**（妖族走妖道系，混血者可跨界访问；杂道 = 两枝之间的嫁接）
- **境界 = 树的深度权限**（凡境只能触碰术法与基础功法，道境才可触碰道的本源）
- 每条叶节点之道都有「道位」与「域主」记录【待定】；器族修器道是从器之内向外走，与人族炼器师从外向内走互为表里
- **试水期只实现三叶**：剑道（青莲剑歌）、阵道（太虚阵经）、火行道（焚天诀）

## 3. 证道之路（境界的世界观映射）

| 阶梯 | 阶名 | 含义 | 世界地位 |
|---|---|---|---|
| **下界之梯** | 凡境 → 灵境 → 真境 → **道境（证道）** | 修一门道，直至成为此道此界之真 | 修士 → 高手 → 长老 → 证道者 |
| **上界之梯** | **合道一域** | 与本域此道相合——**域内此道的规则皆听你号令**；一道之位有定数，须挑战现任域主 | **域主** |
| | **破域飞升** | 超脱本域，前往诸天万域 | 上界来客 |
| | **证天道 / 自证** | 证天道：正统之路，合入四十九大道席位之一，成道主；**自证：立新道，开第五十席，补全「遁去的一」** | 道主级 |
| | **终成大道** | 与大道合一 | 传说·结局级 |

- 下界之梯（凡→道）是本作的**实际游戏内容**；上界之梯是长期愿景（见《路线图》）
- **合道一域 = 域主之争**：玄黄域内每条道的「道位」有定数，证道者想合道，须与现任域主一较高下——「争鸣」的世界观化
- **妖灵道特例**：此道至今无人证得大道，所有证道仅止于妖灵域——离开此域，此道不立。妖灵圣盟的圣人即此道合道者，**却也被此道困于域中**。补全它，正是「自证」主线的支线之一
- **阶梯跨层**：凡→道走的是生灵层（六道→万道）；合道一域 = 掌握一域之规则；破域飞升后，证天道/自证 = 踏入规则层（席位之争）；终成大道 = 与大道合一。神族走天道之路是**捷径**，而非独占

## 4. 域与世界结构

- 本作世界 = **玄黄界**（天地玄黄），诸天万界之一。界内有**诸域**，每域有独立的天地规则与道之显化——**域是道的土壤**：某道介质最盛之地，即此道的立道之域
- **人域三分**：人族世界分为三域，各由一大联盟统辖——

| 域 | 统辖者 | 道之介质 |
|---|---|---|
| **紫微域** | 紫微圣庭（正道联盟） | 灵气清正 |
| **玄魔域** | 万魔圣殿（魔道联盟） | 魔气充盈 |
| **妖灵域** | 妖灵圣盟（妖灵联盟） | 妖灵之力——**妖灵道仅在此域立道** |

- 各族之域【待扩展】：苍梧域（妖族·龙庭）、幽冥域（鬼族·阴司）、蛮荒域（巫部遗民）……
- **域主 = 圣人**：每域有一位合道一域的圣人（男称**圣皇**，女称**圣后**）——合道者即域主（见《修炼体系》上界之梯）
- **时间长河**：贯穿诸域诸时代的时间之河。上游不可溯，下游不可测——**河道的异动是主线悬念**
- **玩法落点**：圣皇圣后 = 合道一域的具象目标（域主之争）；破域飞升 = 离开本界的「上界」内容；时间长河 = 穿越时空玩法——**每个时代都是一个完整的世界快照**（§6），时代间以「落幕事件」衔接，因果可追溯

## 6. 历史纪元（时代快照）

每个时代都有**完整的域之划分与势力格局**——为时间长河玩法预留，时代间以「落幕事件」衔接：

| 纪元 | 域之划分 | 势力格局 | 种族形势 | 力量顶点 | 落幕事件 |
|---|---|---|---|---|---|
| **第一纪·混沌道生** | 天地未分，混沌一气 | 无 | 万灵初醒 | 混沌神魔 | 大道演化，六道雏形立 |
| **第二纪·太古道争** | 天界/人间/幽冥三界初分 | 万族争「道位」 | 祖龙、祖巫、古神并立 | 祖级存在 | **绝地天通**；巫道失落，第七道之位空出 |
| **第三纪·上古洪荒** | 山海格局：大荒、海外、九州 | 巫部林立，妖庭初立 | 山海神兽遍野（《山海经》时代） | 十二祖巫、四灵神兽 | 妖庭内乱；巫族大祭失败，巫族衰落 |
| **第四纪·中古封神** | 天庭立，神位体系定 | 香火神道兴起 | 神族主天，人族渐兴 | 天帝、众神 | 神人分界，神族隐世 |
| **第五纪·近古争鸣** | 人间宗门割据 | 正道魔道分途，十二宗成型；妖灵一脉自域外兴起 | 各族领地分明 | 剑仙、大魔、龙王、鬼帝 | 灵潮初乱 |
| **第六纪·当代灵潮** | 格局延续 + 灵潮涨落 | 三盟十八宗、龙庭、阴司、巫部遗民并立 | 混血渐多，禁忌渐破 | 各道域主（合道者，屈指可数） | **进行中——玩家的时代** |

> 设计纪律：每个时代 = 一个自足的世界配置（地图/势力/种族可用性），未来时间长河玩法直接复用；当代是默认时代。

### 6.1 人族崛起史（道祖传说）

- **上古之弱**：人族无血脉、无体魄天赋，是诸族的口粮与奴隶——最强的人类不过**练气**境界（命门遍布全身，见《修炼体系》§2.1）
- **道祖开道**：一位先贤在绝境中摸索出凝结**金丹**之法——人族尊其为**道祖**（人道之祖；与席位「道主」无关）。道祖云游天下，**悄悄向人族传道**——这是人族「传道全族」传统的开端，也是功法师承体系的文化源头
- **代代探索**：金丹之后，元婴、化神……一代代人前赴后继，把修炼之路一点点向上凿开
- **崛起之策**：**隐忍**——在诸族纷争互相消耗时休养生息；**传道**——功法向全族开放，不私藏秘技；**智慧**——发明创造、与他族贸易往来
- **当代之果**：人族成为最强种族，并摸索出**合道一域成圣**之法——紫微圣庭、万魔圣殿、妖灵圣盟的圣皇圣后体系由此而来
- **玩法落点**：道祖传说 = 拜师/传道/师承体系的世界观来源；「功法向全族开放」解释了人族功法兼容性全开的种族特性

## 8. 势力格局（当代·详版）

人族世界三分，三大联盟各统六宗、各辖一域；联盟之下，大宗统御附属小宗、世俗国家与城邦——**势力金字塔**：

```
圣庭 / 圣殿 / 圣盟（域级：圣皇 / 圣后 = 合道一域的圣人）
 └─ 六大宗（宗级：各设圣子 / 圣女，为下一代圣人竞争者）
     └─ 附属小宗 · 世俗国家 · 城邦（地级）
         └─ 散修与凡人（底层）
```

### 8.4 圣皇圣后与圣子圣女（传承体系）

- **每域圣人**：合道一域的域主，男称**圣皇**、女称**圣后**——三大圣者分属三域，是当代人族的顶点
- **圣子/圣女**：各大宗设圣子圣女，作为下一代圣人的竞争者
- **继位双门槛**：① 政治层——联盟内论道大会、试炼、声望竞争胜出，获得继位资格；② 天道层——须真正**合道一域**（挑战现任域主的道位）
- **玩法落点（P1+）**：玩家可走「弟子 → 真传 → 圣子/圣女 → 圣皇/圣后」的宗门阶梯；圣位争夺是终局级玩法之一

### 8.5 附属结构与凡尘

- **附属小宗**：大宗之下的小门派（如剑宗下辖数十小剑派），大宗通过它们控制地方
- **世俗国家**：宗门庇佑的王朝与诸侯国，提供人口、香火与资源（世俗信仰与香火神道的交汇点）
- **城邦**：坊市、中立城等自治城邦，三大联盟都想拉拢
- **玩法落点**：小宗/国家/城邦 = 任务、声望、资源与因果的网络；玩家后期可扶持、颠覆或自立一方

### 8.6 各族

- **妖族**：龙庭（龙族为尊）、万妖山（群妖）、散妖（化形失败者）
- **鬼族**：酆都阴司（地狱道·秩序）、野鬼流民（饿鬼道·执念）
- **巫族**：巫部遗民（十二祖巫部族后裔，蛰伏待兴）
- **神族**：隐世天庭（神位体系，香火神争位）
- **灵族**：灵墟（避难所）
- **器族**：器冢（无主之器归宿）

**玩法落点**：每宗/每族 = 一条功法接触面 + 因果归属 + 一组任务线。

## 9. 核心悬念（主线钩子）

1. **遁去的一**为何空缺？——主线。自证立新道 = 补全天道
2. **巫道为何失落**？——太古道争之谜；补全天道的两条路之一（找回第七道，见 §1.3）
3. **妖灵道为何未证大道**？——玩家可亲手补全（主线支线）
4. **灵潮为何紊乱**？——当代大事件的根源
5. **时间长河异动**——上游封堵？穿越玩法入口
6. **混血者的禁忌身份**——两族皆斥，注定自立

## 10. 世界观写作纪律

- 每族/每势力先写「玩法落点」再写故事
- 时代快照模块化，为时间长河储备
- 名词控制：每系统 ≤10 个新词
- 参考来源：《道德经》等道家经典（大道层级）、《山海经》（神兽/巫族/洪荒）、《妖神记》（妖灵道、龙墟界域神宗体系）、《众仙俯首》（正魔十二宗）、《逆天邪神》（神魔设定）
