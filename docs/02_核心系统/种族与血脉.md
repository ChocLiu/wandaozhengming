# 种族与血脉

> 状态：初稿 v0.2 · 2026-08-30
> 本系统承载支柱一「道即机制」：**种族不是皮肤**。v0.2 起扩为**八族+隐藏**，每族细分到血脉与支系——不同种族 = 不同的修炼模式 + 不同的世界身份 + 不同的生理规则。

---

## 1. 种族的三层构成

每个种族必须回答三个问题，缺一不可：

1. **修炼模式**：日常修炼做什么、吃什么资源、怎么突破（详见《修炼体系》）
2. **世界身份**：在势力格局中的位置、被谁欢迎、被谁追杀
3. **生理机制**：独有的规则——别的种族想学也学不了的「种族专属机制」

## 2. 八族详述

### 人族——万法皆通，寿元为枷（人道）
- **修炼模式**：可修一切功法（功法兼容性全开），悟性见长；分**正道六宗**（属紫微圣庭）与**魔道六宗**（属万魔圣殿），与妖灵圣盟六宗并称**三盟十八宗**（见《世界观设定》§8）
- **生理机制**：寿元最短（凡境百年）。**每修一门新功法都有寿元成本**——修得越多越强，但越逼近大限。人族的核心张力 = **寿元管理**
- **特殊体质**【隐藏】：道体、剑骨、丹心、纯阳之体、天煞孤星……体质先天决定对某道的亲和，**待玩家发掘**——不写在出生选项里，机缘揭示
- **一句话玩法**：「百艺皆通，但你的时间有限——你修的每一门道，都在燃烧你的命」

### 妖族——龙族为尊，万物可化（畜生道/妖道）
- **修炼模式**：血脉觉醒树 + 吞月华/血食；**进化线见 §3**（本族核心玩法）
- **生理机制**：**本体形态**——真身与化形是两套可切换的规则（真身强但无法进人族城镇、无法用大部分法宝）；化形需渡**化形劫**
- **世界身份**：龙庭（龙族为尊）、万妖山（群妖）、散妖（化形失败者）；被猎妖人/取丹者觊觎
- **封神之兽**：上古曾有神兽封神为「妖神」——凤凰、金乌、麒麟、朱雀、龙神皆是**妖族封神的上古神兽**（神兽进化线的终点），与神族有一段古老恩怨；它们是妖族自己的封神，不是神族的势力
- **一句话玩法**：「你天生拥有力量，而进化的终点，是传说中的神兽」

### 鬼族——执念成形，无实体（饿鬼道+地狱道）
- **细分**：
  - **游魂**（饿鬼道）：凡鬼，执念成形，香火为食
  - **厉鬼**：怨气失控的游魂——强大但接近疯狂
  - **鬼修**：有传承的鬼，走修炼正途
  - **鬼将/鬼王**：香火塑身，一方鬼雄
  - **阴差**（地狱道）：阴司秩序的公务员——**死亡三途的官方机构**（玩家死亡转世时与阴司打交道！）
  - **鬼仙**：度执念（放下）/永执（极恶）而成
- **生理机制**：**无实体**——免疫纯物理类机制（体修的碰撞打不到你！），可附身、穿墙、入梦；被符箓/香火/佛门克制
- **一句话玩法**：「你是一段不肯消散的执念——执念让你存在，也让你不得解脱」

### 魔族——六支并立，以战为生（修罗道）
| 支系 | 机制风味 |
|---|---|
| **天魔** | 魔气正统，魔族贵族，魔气是通用强化剂 |
| **修罗** | **战意不灭**：受击与攻击积累战意，越战越强，怯战则衰（参考《逆天邪神》） |
| **罗刹** | 夜行疾速、魅惑潜杀；男女罗刹异相 |
| **血魔** | 血道：吸血、血祭，血煞为食 |
| **心魔** | 无实体，寄生人心——**突破心魔关的幕后黑手就是它们**（联动《修炼体系》突破事件！） |
| **夜叉** | 低阶战族，数量庞大，可进化入上五支 |

- **生理机制**：魔气侵蚀度——超过失控线则入魔（角色失控/NPC 化），需通过特定行为维持平衡
- **立族之本**：魔祖（始祖神阴面）立**寂灭大道**——神魔同源、分据阴阳；**支系**（天魔/修罗/罗刹/血魔/心魔/夜叉，你是谁）与**势力**（劫天/槃冥/涅轮/九煞/永夜/枭蝶六脉，你属哪一脉，见《世界观设定》§8.6）正交
- **一句话玩法**：「力量唾手可得，只要你不怕变成怪物」

### 巫族——祖巫血脉，失落之族（道外）
- **修炼模式**：**不修元神修体魄与血脉**——巫力源于祖巫血脉、图腾、战舞、祝由与祭祀；与六道诸族的修炼模式**根本不同**
- **十二祖巫血脉**（《山海经》体系，各掌一种天地之力）：

| 祖巫 | 之力 | 祖巫 | 之力 |
|---|---|---|---|
| 祝融 | 火 | 强良 | 雷 |
| 共工 | 水 | 天吴 | 风 |
| 后土 | 土 | 翕兹 | 电 |
| 蓐收 | 金 | 帝江 | 空间 |
| 句芒 | 木 | **烛九阴** | **时间**（时间长河联动！） |
| 玄冥 | 雨/冬 | 奢比尸 | 天气 |

- **生理机制**：图腾之力——图腾柱立于场地即成「信仰范围」（场地面 buff 节点，与阵修的阵图相似但**信仰驱动**而非灵材驱动）；战舞淬体（受击成长与体修同源不同源流）
- **世界身份**：巫部遗民，蛰伏待兴——**巫道本应入六道，太古道争中失落**，巫族是最接近「遁去的一」的种族
- **一句话玩法**：「你们的道被天道抹去了——而你要把它找回来」

### 神族——混沌遗裔，盛极而衰（天道）
- **历史**：祖先是**混沌遗族**；始祖神（盘古）开天辟地，立**空间与创生**二道——其阴面化**魔祖**立**寂灭大道**，神魔同源分据阴阳；众神立时间/生死/秩序/五行/灵慧/信仰/星辰诸道并自称「天道」；因**永恒大道无人可全悟**而寿元耗尽，血脉通婚稀释，盛极而衰（详见《世界观设定》§6.1）
- **细分**（传承参照《逆天邪神》神族体系）：
  - **血脉派**：混沌血脉后裔——天生亲和诸道，但血脉日稀；六大势力分脉：**四创世神直系**（诛天·杀戮 / 秩序 / 生命·生死 / 元素·五行）+ **后起两脉**（梵天·信仰 / 星月·星辰）；元素一脉因「邪神之叛」式微
  - **香火派**：凡俗信仰成神——万民香火塑神位；**神位有限，须争夺**（中古封神是神族以香火续神道的自救）
- **禁忌之章**：元素创世神与劫天魔帝之恋 → 「邪神」之叛 → **神魔禁典**（神魔混修禁忌法）——神魔混血即「堕神」杂道的源头
- **生理机制**：信仰在则神存——**信仰崩塌 = 神陨**；血脉神寿元极长但**非永生**（永恒大道之缺）；香火是可被掠夺的资源
- **世界身份**：太初神殿（联盟）隐世，六大神殿分脉；当代偶有神裔行走人间
- **一句话玩法**：「你的祖先开天辟地，而你的族谱正在衰亡——重振神道，或亲手埋葬它」

### 灵族——五行之灵（道外）
- **细分**：金/木/水/火/土五行之灵 + 风雷冰异灵
- **修炼模式**：天地交感——修炼极慢但极纯，几乎无功法冲突，天生神通
- **生理机制**：**被炼化威胁**——灵族是顶级材料：器修想把你炼成器灵，丹修想把你入药，魔修想吞你。**残酷真相：器灵的前身多是灵族被炼化而来**——灵族与器族之间，隔着一层沉睡的记忆
- **一句话玩法**：「整个世界都想把你炼掉，而你只需要活过今天，就比他们都强」

### 器族——器灵共生（人道·器道）
- **细分**：剑器、钟鼎、琴棋书画、奇门器具
- **修炼模式**：与**器主**绑定共生——器主越强你越强；被祭炼、被使用 = 成长
- **生理机制**：可被**交易/转手**（换宿主 = 换玩法环境）；器主陨落 = 自由或陪葬的抉择；可拥有独立功法（器韵）
- **世界身份**：器冢（无主之器归宿）；剑宗/丹鼎宗视器灵为战略资源
- **一句话玩法**：「你的命运拴在别人手里——选一个值得托付的主人，或者自己挣脱枷锁」

## 3. 妖族进化体系（龙族血脉与神兽进化）

> 妖族的核心成长玩法：**万物皆可化神兽**。妖族的「变强」不是刷经验，而是**返祖进化**。

### 3.1 龙族血脉等级（龙族为尊的内部阶梯）

| 等级 | 存在 | 说明 |
|---|---|---|
| **祖龙** | 仅存传说 | 太古道争时代的顶点，现世不见 |
| **真龙** | 五爪金龙、青龙、应龙、烛龙等 | 血脉纯正，龙族之主族 |
| **蛟龙** | 千年修成 | 真龙之下万妖之上 |
| **龙属** | 虬、螭、鱼龙、蟠龙 | 有龙血，未成龙 |
| **近龙种** | 蛇、鲤、鳝 | 化龙潜力股——进化线起点 |

- **龙族内部血脉**：金龙（至刚）、青龙（木德）、黑龙（水渊）、白龙（云行）、应龙（司雨，有翼）、**烛龙（司夜，时间传说——与时间长河联动）**
- 龙族血脉浓度 = 妖族内最高贵的「进化资产」，可提纯、可争夺、可混血
- 祖龙即上古「妖神」**龙神**（太古苍龙）——妖族封神之路的顶点之一（见妖族详述·封神之兽）

### 3.2 神兽进化线（每个小妖都有上古神兽血脉）

**任何一个小妖都有一条通往上古神兽的进化之路**——进化 = 血脉浓度 + 机缘 + 返祖劫：

| 起点 | 进化链 | 终点（《山海经》神兽） |
|---|---|---|
| 蛇 | 蛇 → 蛟 → 龙 | 真龙/烛龙 |
| 鲤 | 鲤 → 鱼龙 → 螭/应龙 | 应龙 |
| 麻雀 | 麻雀 → 青鸾 → 凤凰 | 凤凰/朱雀 |
| 狐狸 | 狐狸 → 多尾 → 九尾狐 | 九尾狐 |
| 猿 | 猿 → 灵猿 → 朱厌/无支祁 | 朱厌/无支祁 |
| 龟 | 龟 → 灵龟 → 玄武 | 玄武 |
| 虎 | 虎 → 灵虎 → 白虎 | 白虎 |
| 鹏 | 鹏 → 大鹏 → 鲲鹏 | 鲲鹏 |
| 乌鸦 | 乌鸦 → 金乌 | 金乌/九凤 |

**神兽图鉴（进化终点，部分）**：四灵（青龙/白虎/朱雀/玄武）、四凶（饕餮/穷奇/梼杌/混沌）、麒麟、凤凰、鲲鹏、应龙、烛龙、九凤、白泽、九尾狐、金乌、毕方……

### 3.3 进化玩法落点

- 进化是**事件**（返祖劫），不是攒条——需要血脉浓度达标 + 机缘触发 + 渡劫
- 进化改变**规则**而非数值：蛟化龙解锁「呼风唤雨」（场地规则改写）、雀化凤解锁「浴火重生」（死亡规避规则）
- 与混血系统联动：妖+人混血者的进化线出现**分支**（化形 vs 返祖的抉择）
- 与自创功法联动：神兽血脉 = 参悟妖族功法的元件来源（见《功法系统》）

## 4. 血脉系统（混血核心）

### 4.1 血脉 = 修炼权限包

血脉本质是**遗传的规则访问资格**：妖血带来进化线与血脉觉醒树，灵血带来天地交感，鬼血带来无实体天赋，巫血带来祖巫之力。血脉浓度决定你能用多少：

- **血脉浓度**：双血统按比例构成（如「七分妖血三分人血」），动态可变：丹药提纯 / 献祭稀释 / 机缘突变
- 浓度阈值解锁层级：≥30% 解锁该族基础机制，≥70% 解锁深层机制

### 4.2 血脉冲突（混血的代价）

- 异血互斥产生**冲突值**，来源：修炼异族功法、使用异族机制、时间推移
- 冲突值在安全区内：**杂道可用**（§4.3）
- 冲突值超阈值：**血脉反噬**——双修皆废 / 失控化妖 / 寿元剧减
- 调和手段：丹药、调和类功法、机缘——**混血玩家要持续管理冲突**，这本身是一条核心循环

### 4.3 混血优势：杂道

混血者独有的「杂交机制」，纯血永远无法获得：

| 混血 | 杂道示例 |
|---|---|
| 妖+人 | **妖剑修**：本体形态的剑法（妖身出剑，化形收剑） |
| 鬼+丹 | **药鬼**：把鬼仆炼成活体丹炉 |
| 魔+剑 | **血魔剑**：以血养剑、以剑饮血 |
| 灵+阵 | **灵阵**：以身为阵脚，阵法长在血脉里 |
| 巫+妖 | **巫妖**：图腾养兽，兽血祭图腾 |
| 神+魔 | **堕神**：神格染魔气，禁忌之力 |
| 人+神 | **神裔**【隐藏】：隐藏血脉，机缘觉醒 |

**关键联动**：杂道功法世界内几乎没有现成的——**混血玩家的核心玩法就是自创功法**。混血 = 自创系统的进阶入口。

### 4.4 血脉觉醒

机缘事件解锁祖血记忆：妖族老祖传承、祖巫血脉、神裔觉醒、龙血复苏……觉醒 = 获得种族专属机制的一次性机会，但通常伴随代价（引来觊觎者）。

## 5. 出生设计（开局）

开局选择 **种族 + 出身**，出身决定三件事：初始功法接触面、初始资源、初始因果。所有路线后期均可改（开放沙盒），出身只影响开局体验。

|---|---|---|

| 尸傀宗杂役 | 尸傀道残篇 | 被正道通缉 |

## 7. 隐藏项（待玩家发掘）

> 原则：只写钩子，不写死——隐藏项是留给玩家自己发现的「惊喜」，也是策划的弹性空间。

- **混沌遗族**：神族先祖（谜团半揭）——纯血是否仍有存续？（见《世界观设定》§6.1）
- **时间之民**：烛九阴血脉相关，传说居于时间长河之畔——穿越玩法的引路人？
- **神裔**：人神混血的隐藏血脉，神位继承者？
- **转世大能**：轮回机制下，你可能本来就有一段被封印的前世……

## 8. 范围控制（重要）

- **P0 原型**：只做人族（剑/阵/丹三道的机制在战斗层面先跑通）
- **P2 起**：加入妖族 + 混血血脉 + 龙族血脉线雏形（验证杂道与进化玩法）
- **P3 起**：鬼/魔/灵/器/巫/神逐个加入——**每个新种族都是一整个玩法模块**，绝不一次性全铺开
- **隐藏项**：正式版后的内容更新位，不占开发主线
