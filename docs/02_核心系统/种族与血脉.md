# 种族与血脉

> 状态：初稿 v0.1 · 2026-08-30
> 本系统承载支柱一「道即机制」：**种族不是皮肤**——不同种族 = 不同的修炼模式 + 不同的世界身份 + 不同的生理规则。血脉系统承载「混血不同种族血脉」的差异化野心。

---

## 1. 种族的三层构成

每个种族必须回答三个问题，缺一不可：

1. **修炼模式**：日常修炼做什么、吃什么资源、怎么突破（详见《修炼体系》）
2. **世界身份**：在势力格局中的位置、被谁欢迎、被谁追杀
3. **生理机制**：独有的规则——别的种族想学也学不了的「种族专属机制」

## 2. 六族详述

### 人族——万法皆通，寿元为枷
- **修炼模式**：可修一切功法（功法兼容性全开），悟性见长
- **生理机制**：寿元最短（凡境百年）。**每修一门新功法都有寿元成本**——修得越多越强，但越逼近大限。人族的核心张力 = **寿元管理**（续命丹、延寿功法、突破续命）
- **世界身份**：当世主角种族，四大方向（剑宗/丹盟/阵阁/魔道散修）对应初始功法接触面
- **一句话玩法**：「百艺皆通，但你的时间有限——你修的每一门道，都在燃烧你的命」

### 妖族——血脉为本，化形为槛
- **修炼模式**：血脉觉醒树（种族天赋树）+ 吞月华/血食
- **生理机制**：**本体形态**——妖有真身，真身状态与化形状态是两套可切换的规则（真身强但无法进人族城镇、无法用大部分法宝）。化形需渡**化形劫**
- **世界身份**：万妖山正统 vs 散妖流亡者；被猎妖人/取丹者觊觎
- **一句话玩法**：「你天生拥有力量，但为了进入文明世界，你必须把它藏进人皮」

### 鬼族——执念成形，无实体
- **修炼模式**：执念任务链驱动，香火/怨气为食
- **生理机制**：**无实体**——免疫纯物理类机制（体修的碰撞打不到你！），可附身、穿墙、入梦；但被符箓/香火/佛门克制（天敌机制）
- **世界身份**：酆都阴司（秩序鬼）vs 野鬼（执念失控者）
- **一句话玩法**：「你是一段不肯消散的执念——执念让你存在，也让你不得解脱」

### 魔族——以杀证道，魔气噬主
- **修炼模式**：杀戮获取魔气；魔气可**魔化**任何功法（给任意功法注入魔气→「魔化变体」，机制强化+风险）
- **生理机制**：魔气侵蚀度——超过失控线则入魔（角色失控/NPC化），需通过特定行为（斩杀强敌/静修/丹药）维持平衡。高风险高回报
- **世界身份**：被正道追杀，魔道散修抱团
- **一句话玩法**：「力量唾手可得，只要你不怕变成怪物」

### 灵族——天地交感，纯粹而缓
- **修炼模式**：修炼极慢但极纯（功法兼容性天然高、几乎无冲突），天生神通
- **生理机制**：**被炼化威胁**——灵族是顶级材料：器修想把你炼成器灵，丹修想把你入药，魔修想吞你。灵族玩法 = 隐藏身份 + 保护自己 + 复仇线（可与其他种族玩法正交叠加）
- **世界身份**：灵墟避难所；对丹盟/器冢有世代仇恨
- **一句话玩法**：「整个世界都想把你炼掉，而你只需要活过今天，就比他们都强」

### 器族——器灵共生，被使用中成长
- **修炼模式**：与**器主**绑定共生——器主越强你越强；被祭炼、被使用 = 成长
- **生理机制**：可被**交易/转手**（换宿主 = 换玩法环境）；器主陨落 = 自由或陪葬的抉择。可拥有独立功法（器韵）
- **世界身份**：器冢（无主之器归宿）；丹盟/剑宗都视器灵为战略资源
- **一句话玩法**：「你的命运拴在别人手里——选一个值得托付的主人，或者自己挣脱枷锁」

## 3. 血脉系统（混血核心）

### 3.1 血脉 = 修炼权限包

血脉本质是**遗传的规则访问资格**：妖血带来血脉觉醒树的入口，灵血带来天地交感，鬼血带来无实体天赋。血脉浓度决定你能用多少：

- **血脉浓度**：双血统按比例构成（如「七分妖血三分人血」），动态可变：丹药提纯 / 献祭稀释 / 机缘突变
- 浓度阈值解锁层级：≥30% 解锁该族基础机制，≥70% 解锁深层机制

### 3.2 血脉冲突（混血的代价）

- 异血互斥产生**冲突值**，来源：修炼异族功法、使用异族机制、时间推移
- 冲突值在安全区内：**杂道可用**（见 3.3）
- 冲突值超阈值：**血脉反噬**——双修皆废 / 失控化妖 / 寿元剧减
- 调和手段：丹药、调和类功法、机缘——**混血玩家要持续管理冲突**，这本身是一条核心循环

### 3.3 混血优势：杂道

混血者独有的「杂交机制」，纯血永远无法获得：

| 混血 | 杂道示例 |
|---|---|
| 妖+人 | **妖剑修**：本体形态的剑法（妖身出剑，化形收剑） |
| 鬼+丹 | **药鬼**：把鬼仆炼成活体丹炉 |
| 魔+剑 | **血魔剑**：以血养剑、以剑饮血 |
| 灵+阵 | **灵阵**：以身为阵脚，阵法长在血脉里 |

**关键联动**：杂道功法世界内几乎没有现成的——**混血玩家的核心玩法就是自创功法**（详见《功法系统》）。混血 = 自创系统的进阶入口。

### 3.4 血脉觉醒

机缘事件解锁祖血记忆：妖族老祖传承、神裔血统、灵脉共鸣……觉醒 = 获得种族专属机制的一次性机会，但通常伴随代价（引来觊觎者）。

## 4. 出生设计（开局）

开局选择 **种族 + 出身**，出身决定三件事：初始功法接触面、初始资源、初始因果。所有路线后期均可改（开放沙盒），出身只影响开局体验。

| 示例出身 | 初始接触面 | 初始因果 |
|---|---|---|
| 剑宗外门弟子 | 剑修功法入门 | 师门规矩约束 |
| 丹盟学徒 | 炼丹入门 | 欠药圃债务 |
| 魔道弃徒 | 魔功残篇 | 被正道通缉 |
| 混血禁忌儿 | 父母各一门残篇 | **两族皆排斥** |
| 野鬼 | 执念任务链 | 生前之谜 |

## 5. 种族关系网（冲突 = 内容）

| 关系 | 说明 | 玩法落点 |
|---|---|---|
| 灵族 × 器/丹/魔 | 猎杀关系 | 灵族玩家的逃生/复仇线 |
| 鬼族 × 符箓/佛门 | 天敌克制 | 鬼族玩家的威胁来源 |
| 妖 × 人 | 猎妖取丹 | 双方都有理由开战 |
| 坊市 | 绝对中立 | 各族共存的经济枢纽 |

## 6. 范围控制（重要）

- **P0 原型**：只做人族（剑/阵/丹三道的机制在战斗层面先跑通）
- **P2 起**：加入妖族 + 混血血脉（验证杂道玩法）
- **鬼/魔/灵/器**：P3 起逐个加入——每个新种族都是一整个玩法模块，绝不一次性全铺开
