# 装备系统（穿戴槽位与储物规则）

> 状态：初稿 v0.1 · 2026-09-02
> 阶段：**P2 起开发**（P1 只留数据位——武器换装在 P0.5 已有雏形）。P0/P1 不阻塞。
> 定位：装备的**穿戴层**——槽位结构与储物规则；装备本身的机制设计沿用《成长与经济》§5 法宝系统（道的载体、有来历、反词条）。
> 界面参照：**暗黑破坏神式**自由槽位（左手/右手自由放、双手武器占满两格）。

---

## 1. 设计红线（先立规矩）

- [ ] **槽位学暗黑，装备学仙侠**：暗黑式的槽位自由度 + 暗黑式的界面结构，**绝不做暗黑式的词条掉落**——装备仍是「道的载体」，有来历、有器灵（可选）、有机制，获取靠传承与因果（《成长与经济》§5）
- [ ] 禁止随机词条、禁止品质颜色、禁止「刷装备」——槽位多 ≠ 堆数值
- [ ] 槽位是**身体部位的延伸**：部位受伤/被毁 → 对应槽位的装备失效或掉落（联动《战斗系统》§2.5 部位伤效）

## 2. 穿戴槽位（暗黑式）

### 2.1 槽位表

| 部位 | 槽位 | 数量 | 说明 |
|---|---|---|---|
| 手 | **左手 / 右手** | 2 | 自由放置：单手武器占一格；**双手武器占满两格**；副手可放法器/短刃/符牌 |
| 头 | **头饰**（冠/簪/斗笠） | 1 | 与耳饰、颈饰**分格独立**，互不占用 |
| 头 | **耳饰** | 1 | 成对视为一件【待定：是否左右耳各一格】 |
| 颈 | **颈饰**（颈环/护符/道锁） | 1 | 咽喉部位——与「咽喉」要害同域 |
| 手指 | **戒指 ×10** | 10 | **每根手指一格**，十指十戒（储物戒/护身戒/契约戒/道戒……见 §4） |
| 躯干 | 法袍 / 内甲 | 1 | 【建议补全，待定】 |
| 腰 | 腰带 / 玉佩 | 1 | 【建议补全，待定】 |
| 足 | 足履 | 1 | 【建议补全，待定】 |

- 槽位界面：角色剪影 + 各槽位格子（暗黑式布局）；P1 简版只做 左右手+头饰+耳饰+颈饰，**手指十格与储物规则 P2 完整版**
- 换装规则：战斗中**武器槽可换**（换装已有——切换功法自动换装），其余槽位**战斗外换装**（除特殊功法【待定】）

### 2.2 左右手自由模式（暗黑式核心）

- 单手武器占一格，**另一手自由**：副手法器（施法媒介，玄术威力/命中挂钩）、副手短刃（招架值加成——联动招架对抗《战斗系统》§5.1.3）、符牌（符道道具）
- **双手武器占满左右手两格**（枪/重剑/弓——对应功法 arm_usage「双臂持械」）
- 惯用手联动：默认主用臂=右手；主用臂被毁 → 换手（《战斗系统》§2.5）——**武器也随之转到副手格**，换手惩罚照旧（攻击/招架 ×0.8）
- 双手武器使用者主臂重伤/毁 → 双手招式禁用（§2.5 硬规则）——只能弃械换单手武器（若行囊有）

## 3. 装备与部位联动（部位伤效的装备侧）

| 部位状态 | 装备后果 |
|---|---|
| 手臂轻伤/重伤 | 该手武器/法器**减效**（攻击/招架乘区，§2.5 伤档修正表） |
| 手臂毁 | 该手装备**掉落**（脱手——武器/法器散落在地格，可被捡走！） |
| 手指伤/毁 | 该指戒指失效/脱落（手指格与部位状态同步） |
| 头部（耳/颈）受伤 | 头饰/耳饰/颈饰按部位状态受损或毁（护体类装备优先被磨——破防模型的「磨防」落在装备耐久上） |

- **磨防 = 磨装备**：破防模型里「防御略高→被磨」磨掉的就是该部位装备的耐久（耐久归零=装备损坏，需修复）——装备耐久与部位状态是一套账
- **器族特例**：器族玩家本体即装备——器族的「穿戴界面」就是本体重铸界面（联动《种族与血脉》）

## 4. 戒指：十指十戒

每根手指一格，共十格——仙侠传统「十指十戒」，但**戴戒有讲究**：

| 戒指类别 | 机制风味 |
|---|---|
| **储物戒** | 空间规则容器（见 §5 储物规则） |
| **护身戒** | 触发类防御机制（濒死护罩/一次替死【稀有】）——机制触发，非属性加成 |
| **契约戒** | 妖灵契/鬼契/婚约信物——契约类功法的装备接口（《妖灵契》联动） |
| **道戒** | 增幅某道机制（剑道戒=剑意上限+1 层——**机制增幅**，非数值） |
| **信物戒** | 师承/家族/盟约——**因果钩子**（戴着它，仇家认得你） |

- **十指皆环的代价**【待定，设计方向】：① 招摇——怀璧其罪，劫修觊觎、正道侧目（因果系统）；② 结印干扰——副手结印功法戴满戒指 → 熟练度临时降档（与 §2.5 arm_usage 联动）——戴得越多，掐诀越笨拙，取舍自定
- 戒指与手指状态同步：手指被毁 → 该戒脱落于地（可被捡走——「杀人夺宝」的落点）

## 5. 储物规则：空间不嵌套（世界法则）

> 这是本条设计最重要的部分——不是物品规则，是**世界规则**。

### 5.1 基本规则

- **储物戒（及一切空间规则容器：乾坤袋/洞天法宝/须弥芥子）不可放入其他空间规则容器中**——无论佩戴与否，凡具空间规则之道具，一律**不得收纳于其他空间容器**
- 储物道具只能放在**无空间规则的载体**里：随身普通口袋（行囊）、箱子、货架、马车
- 推论：**行囊 = 普通口袋**（无空间规则，容量有限）；储物戒**佩戴时**才展开空间（不戴=死物）；多只储物戒轮换佩戴，行囊里可以背着一串戒指，但打不开

### 5.2 推广为世界法则：「空间不叠空间」

- **世界观表述**：空间大道（至高九道之一）的第一法则——**空间不叠空间**。这正是「储物戒不能进储物戒」的根源：不是设计偷懒，是道的法则
- **统一约束**（为后续系统立规，避免各写各的）：
  | 系统 | 受约束行为 |
  |---|---|
  | 阵道 | **阵中不可布阵**（套阵禁止——阵修的一条硬约束，也是勘阵的落点） |
  | 领域 | 域中不可开域（真境领域机制 P2+，同律） |
  | 传送/飞升 | 携空间道具过传送阵需专门法门或额外代价【待定】 |
  | 死亡掉落 | 储物戒被击杀掉落时**藏不进另一个空间**——战利品=真战利品（因果寻仇的赌注） |
- 玩法意义：**「空间」成为一种稀缺资源位**——你只能背一个普通行囊，把什么放进储物戒、背几只在身上，是资产安全与便利的博弈（储物戒全放行囊=方便但被偷/掉落全失；藏在秘境某处=安全但不便携）

## 6. 阶段与路线

- **P1（简版）**：左右手自由槽位（单手/双手/副手）+ 头饰/耳饰/颈饰——战斗原型直接相关（武器换装已有雏形）
- **P2（完整版）**：手指十格 + 储物规则 + 磨防=磨装备耐久 + 部位-装备同步
- **P3+**：器族穿戴界面、法宝器灵认主流程

## 7. 评审检查单

- [ ] 槽位自由度是暗黑式的，装备内容是仙侠式的（无词条无颜色）
- [ ] 空间不嵌套规则是否与既有系统（行囊/掉落/阵道）完全一致，无例外
- [ ] 手指十格是否有机制意义（戒指类别表≥5 且各有反制），而不是堆 10 个数值件
