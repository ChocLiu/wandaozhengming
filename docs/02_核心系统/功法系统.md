# 功法系统（核心创新）

> 状态：初稿 v0.2 · 2026-08-30
> 本系统是《万道争鸣》的**心脏**，承载三大支柱的全部：功法即机制（支柱一）、万法皆可组（支柱二）、自创功法改变世界（支柱三）。

---

## 0. 定义与红线

**功法 = 机制包**。每门功法必须引入至少一条「其他功法没有的规则」，并拥有自己的玩法循环。

红线：
- [ ] 禁止纯数值功法（「攻击力 +10%」直接枪毙）
- [ ] 每门功法必须有**反制手段**（没有天敌的机制不进游戏）
- [ ] 每门功法必须声明自己的「交互面接口」（见下节）——没有声明的功法不能进组合系统

## 1. 六大交互面（组合系统的地基）

所有功法机制读写这六个「面」。**组合 = 面的对接**：功法 A 向某面产出，功法 B 从该面消费，即可组合。这六面是全游戏的「接口语言」：

### ① 状态面（挂在单位上）
单位携带的状态/标记：灼烧、剑意、中毒、道心蒙尘、淬体进度、血毒……
> 例子：《青莲剑歌》产出「剑意」状态；《焚天诀》消费「气血」状态。

### ② 资源面（单位或全局的可消耗物）
灵力、气血、寿元、香火、怨气、神识、灵石、魔气……
> 例子：《焚天诀》烧气血产火势；阵修布阵烧灵石。

### ③ 场地面（战斗空间的地格）
阵图、地形、领域、灵脉节点、雷域、火势蔓延区……
> 例子：《太虚阵经》往地格写「阵图节点」；《焚天诀》把地格改写成「火区」。

### ④ 单位面（场上的实体列表）
本体、召唤物、鬼仆、灵植、化身、器灵……
> 例子：《万鬼幡》往单位面添加「鬼仆」；《万物生》添加「灵植」。

### ⑤ 时序面（时间线）
行动顺序、冷却、预知、延迟结算、时停……
> 例子：《天机演》窥探并改写未来的时序分支；几乎所有功法都有「每 N 回合」的时序声明。

### ⑥ 部位面（挂在单位上的身体结构）
单位的身体分解：眉心（识海）/ 大脑 / 面门 / 咽喉 / 胸 / 丹田 / 四肢……（见《战斗系统》§2）
> 例子：《青莲剑歌》的剑谱专打咽喉手腕；《金石体》攻击全身；神魂功法直取眉神识海。

**组合原理示例**：《青莲剑歌》（剑修·状态面产出剑意）+《太虚阵经》（阵修·场地面）→ 把剑意导入阵图节点 = **太虚剑阵**（合击机制）。两个机制都不是为对方设计的，但接口对上，新玩法自然涌现——这就是「万法皆可组」。

## 2. 功法数据结构（数据驱动声明）

每门功法是一个数据资源，声明以下字段（Godot 中即一个自定义 Resource）：

```
功法声明 {
  id / 名称 / 道系 / 稀有度
  类别: 体修 / 玄修 / 神魂 / 混修（决定主消耗池）
  核心循环: 机制描述（代码实现该循环）
  产出声明: [{面, 类型, 速率/条件}]
  消耗声明: [{面, 类型, 速率/条件}]
  接口声明: [可挂载到哪些面, 接受哪些面的输入]
  冲突表: [与哪些功法抢同一面]
  部位倾向: [攻击偏好部位, 防御侧重]
  境界要求: 每境解锁哪层机制（境界=权限，见《修炼体系》）
  寿元成本: 修炼/突破的寿元代价
  反制表: 被什么克制
}

### 2.1 功法类别（与修炼三脉对应）

| 类别 | 主消耗池 | 特点 | 示例 |
|---|---|---|---|
| 体修功法 | 体力 | 近战肉身、受击成长 | 《金石体》 |
| 玄修功法 | 玄力 | 术法、剑气、元素 | 《焚天诀》《青莲剑歌》 |
| 神魂功法 | 魂力 | 攻神识 / 元神 / 识海 | 《天机演》（神魂属性） |
| 混修功法 | 多池 | 兼容性高、寿元成本重 | —— |

- 类别是功法的**第二分类轴**，与「道系」（剑 / 丹 / 阵……）正交：剑道之下有体修剑法、玄修剑诀、神魂剑意
- **解耦的纯脉专用功法稀有罕见**：多为上古流传（如体修上古功法）；后世大能常将其改造为高兼容性的混修版——「原版」与「改造版」构成功法的收藏与参悟深度
```

## 3. 示例功法（八门，机制各不相同）

> 试水期只实现标 ★ 的三门；其余为设计参照，验证「机制各异」的可行性。

### ★《青莲剑歌》——剑修·连击谱系（状态面）
- **核心循环**：招式必须按「剑谱」顺序打出（如 起→承→转→合），连续命中积累**剑意**；剑意分三层，每层解锁变招（剑谱外的新招式）
- **风险**：谱被打断/被闪避 → 剑意溃散，已积累的层数清空
- **玩家体验**：记谱 + 节奏 + 预判对手打断时机——玩的是「节奏的决策版」
- **反制**：心魔类功法（直接攻击「道心」状态）、高闪避、打断技能
- **辅修适配**：产出「剑意」到状态面，任何消费状态的辅修都能接

### ★《太虚阵经》——阵修·空间预置（场地面）
- **核心循环**：战斗前/中把「阵图节点」布在地格上，节点按阵谱连线成阵；敌人踏入阵区触发连锁效果；阵可被拆除/反制
- **变体玩法**：战斗中移动节点、诱敌入阵、以阵养阵（阵吸收战斗残留灵气自我强化）
- **玩家体验**：空间规划 + 行为预判——玩的是「请君入瓮」
- **反制**：勘阵术（看到阵图节点）、踏阵位规避、远程攻击拆节点
- **辅修适配**：场地面是最开放的面，几乎所有功法都能与之组合（剑意灌阵、丹气入阵、火烧阵……）

### ★《焚天诀》——火系·自燃循环（资源面+场地面）
- **核心循环**：点燃自己——烧气血/寿元换取**火势**；火势按回合蔓延全场（地格→火区），灼烧敌我双方
- **博弈**：火势是双刃剑——烧死敌人前先别烧死自己；雨/水场地克制，风系功法助燃
- **玩家体验**：资源管理与火势控制的极限平衡
- **反制**：水/冰系、灵雨场地、熄灭类状态
- **辅修适配**：产出「火势」到资源面+场地面，体修辅修 = 火体（淬体进度加速火势）

### 《万物生》——木系·灵植生态（单位面+时序面）
- **核心循环**：场上种灵植，灵植有生长周期（时序面），开花结果提供资源/攻击/领域效果；一片小生态就是你的战斗系统
- **玩家体验**：经营与节奏——前期羸弱，生态成型后滚雪球
- **反制**：拔根、焚烧、杀虫

### 《万鬼幡》——鬼系·收魂养鬼（单位面）
- **核心循环**：战败敌人的魂魄收编为鬼仆，**鬼仆保留生前部分功法特性**（！）；战斗 = 指挥鬼仆协同，鬼仆可被超度（损失）
- **玩家体验**：收集 + 排兵——你的敌人变成你的军队
- **反制**：佛门/符箓超度、驱鬼

### 《天机演》——玄系·推演预知（时序面）
- **核心循环**：消耗神识窥见未来 N 回合的推演分支，每场战斗可重选一次行动（时停回卷）；高境界可看到更多分支
- **玩家体验**：信息博弈——知道得越多越强，但推演本身烧神识（资源）
- **反制**：蒙蔽天机类功法（污染推演结果）、神识压制

### 《金石体》——体修·受击成长（状态面）
- **核心循环**：无主动招式——碰撞即伤，受击积攒「淬体进度」，进度满战斗中**当场进化**（临时获得新规则：如「反震」「金刚」）
- **玩家体验**：挨打的艺术——故意吃伤害换进化时机
- **反制**：内伤类（绕过体表）、放风筝

### 《血魔经》——魔修·血毒循环（资源面）
- **核心循环**：吸血强化一切属性与功法，但积攒**血毒**；血毒超阈值 → 失控（敌我不分）；特定行为排毒（放血给敌人、静修、丹药）
- **玩家体验**：风险控制——强是即刻的，代价是滞后的
- **反制**：净化类、防止吸血的护体

### 《妖灵契》——人族·妖灵道·契约共生（单位面+资源面）
- **核心循环**：以灵魂力契约妖灵，妖灵**保留自我意志**；战斗中与妖灵共战、共鸣、合体；可契约多只组成「灵队」，可换灵、放归
- **特色**：妖灵有性格与忠诚度，强扭的契不甜——**关系经营是战力的一部分**（参考《妖神记》妖灵师）
- **玩家体验**：收集 + 培养 + 关系经营；与《万鬼幡》的强制收魂相反，妖灵道是**双向契约**
- **反制**：灵魂力透支、夺灵/超度类、灵约反噬
- **世界观联动**：妖灵道未证大道、仅止于本域——补全此道是「自证」主线的支线之一

### 魔道功法示例（扩展，P2 起）

| 功法 | 机制一句话 |
|---|---|
| 《尸傀经》 | 以尸体/灵材炼傀（单位面）：傀儡保留生前部分招式，材料驱动，可被「斩灵」反制 |
| 《修罗战意》 | 战意不灭（状态面）：受击与攻击积累战意，越战越强，怯战则衰——为战而生的循环 |
| 《万毒蛊术》 | 蛊虫经济（状态面+资源面）：养蛊、下蛊、以毒攻毒，蛊反噬风险 |

## 4. 组合系统：主辅修

### 4.1 基本规则
- **主修 1 门**：决定战斗的主体循环
- **辅修 0~2 门**：辅修的机制被简化，通过接口**挂载**到主修的循环里（如阵修辅修剑修：剑意注入阵图，而非完整布阵）
- 辅修位随境界解锁（灵境 +1，道境 +1）

### 4.2 组合合法性（接口匹配）
- **冲突**：两门功法抢同一资源面 → 互斥（如《焚天诀》+《血魔经》都烧气血，不能同时主辅）
- **兼容**：接口互补 → 可组合，各玩各的（弱联动）
- **共鸣**：特定组合触发**合击机制**（强联动，精选设计过，不是任意两两都有）

### 4.3 共鸣示例（精选合击）
| 组合 | 合击机制 |
|---|---|
| 剑意 × 阵图 | **太虚剑阵**：剑意化作阵中剑气，阵随剑意运转 |
| 丹气 × 鬼仆 | **药鬼**：鬼仆成为活体丹炉，产出丹药强化自身 |
| 淬体 × 火势 | **火体**：淬体进度加速火势蔓延，体魄越强火越旺 |
| 推演 × 灵植 | **天机园**：推演出灵植生长的最优时序 |

> 设计意图：**自由组合（人人可试）+ 精选共鸣（给目标感）**。共鸣表是内容，随版本扩充；组合涌现是系统，永远开放。

## 5. 自创功法（三层递进）

### L1 嫁接（人人可做，随时可改）
主辅组合本身即「自创」——选择你的主修辅修搭配，形成个人「道途」。低风险，随时调整。

### L2 推演（消耗悟性，有风险）
修改已有功法的模块：调参数、换组件（如把《青莲剑歌》的「剑意」换成「刀意」——状态面类型替换）。
- 成本：悟性 + 道藏（功法典籍，世界内稀缺资源）
- 风险：走火入魔——失败则功法受损、角色受伤（roguelike 式赌注）
- 产出：个人改良版功法（可命名，如「某某改·青莲剑歌」）

### L3 立道（终极自创：道种编辑器）
从**机制元件库**拼装全新功法：

```
新功法 = 触发条件 × 作用对象 × 效果机制 × 资源循环
例：受击时(触发) × 敌方单位(对象) × 反震(效果) × 消耗淬体进度(资源)
```

- **元件库**：触发（受击时/回合开始/踏入某格/连续命中 3 次/死亡时……）、对象（自身/敌方单位/场地/全局）、效果（灼烧/召唤/位移/预知/吸收/转化……）、资源（消耗/产出声明）
- **元件获取 = 参悟**：从你已学的功法中「参悟」出元件——学的功法越多，元件库越大 → **收集功法 = 解锁创作空间**（探索驱动力，替代抽卡收集）
- **证道门槛**：拼装完成后需**证道**——用新功法完成一场验证战（渡劫/斩一名真境强敌/论道胜宗师）。成功 → 功法定型、可命名、进入世界功法库；失败 → 功法残缺（永久缺陷）或反噬
- **限制**：悟性/道心门槛，证道机会稀缺（证道需机缘）

### 5.1 世界功法库与传承（自创改变世界）
- 立道成功的功法进入**世界功法库**：NPC 可以学习、改良、传授
- 玩家可以**开宗立派**：立你的道为宗门传承，收徒（NPC 会来拜师）
- NPC 也会自创/改良功法，改良版可能回流到你手里——**世界是活的**
- 主线联动：立道 → 道统传播 → 争鸣天下 → 补全「遁去的一」（世界观主线，见《世界观设定》）

## 6. 功法获取（无抽卡）

| 途径 | 机制 | 代价/因果 |
|---|---|---|
| **拜师** | 加入门派/拜入师门 | 人情、师承义务、门派规矩约束 |
| **机缘** | 奇遇/秘境/讲道大会 | 世界探索 + 气运 |
| **感悟** | 与某机制深度交互后「悟」出残篇（如被剑修击败多次，悟出剑道残篇） | 时间 + 经历 |
| **抢夺** | 击败对方夺取功法 | **因果**：对方师门/家族追杀 |
| **交易** | 坊市购买 | 灵石——但高级功法不流通，靠缘分 |
| **自创** | L1/L2/L3 | 见上节 |

> 当代人族世界三分：**紫微圣庭**（正道六宗）、**万魔圣殿**（魔道六宗）、**妖灵圣盟**（妖灵六宗）——三盟十八宗构成初始功法接触面，各有规矩与因果（详见《世界观设定》§8）。

## 7. 平衡哲学（无数值怎么平衡？）

本游戏没有数值面板，平衡的唯一标准是**可反制性**：
- 每个强机制必须有反制（焚天怕水、剑意怕心魔、鬼仆怕超度）
- 克制关系做成**机制级**的，而非数值级（水克火 = 浇灭火势的规则，不是伤害 +50%）
- 测试方法：确定性战斗模拟 + 回放（技术方案见《Godot技术选型与架构》），用 AI 对手批量自对弈发现无解组合
- 组合爆炸控制：接口匹配规则 + 共鸣精选 + 证道稀缺，三层闸门防止「无限组合失控」
