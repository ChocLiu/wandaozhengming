# 万道争鸣（暂定名）

> 一款**机制驱动**的开放沙盒修仙 RPG：每个种族、每门功法都带来一套真正不同的玩法机制，成长来自悟道与机缘，而不是刷数值。2D 像素/手绘 · 回合制策略 · Godot 4。

## 一句话定位

**不是抽卡练级堆数值，而是「道即机制、万法皆可组、世界是活的修途」。**
